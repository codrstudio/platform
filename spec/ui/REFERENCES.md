## Servidor MCP

Segue um resumo direto e prático da página sobre **MCP Server do shadcn/ui**:

**O que é:**
- O **MCP Server** (Model Context Protocol Server) é uma solução para integrar assistentes de IA com registries (repositórios) de componentes UI.
- Ele permite que você navegue, pesquise e instale componentes diretamente em seu projeto, usando linguagem natural (prompts para IA).

**Para que serve:**
- **Busca de componentes**: Liste ou procure qualquer componente, bloco ou template disponível em registries compatíveis.
- **Instalação fácil**: Comandos como “adicionar formulário de login” podem ser processados por IA e convertidos em operações reais.
- **Suporte a múltiplos registries**: Acesso tanto ao registry padrão do shadcn/ui quanto a registries terceiros ou privados.
- **Interação Natural**: A IA traduz perguntas comuns em comandos para instalar ou listar componentes.

**Como usar:**
1. **Configuração do Registry**
   - Configure registries no arquivo `components.json` do projeto. Exemplo:
     ```json
     {
       "registries": {
         "@acme": "https://acme.com/r/{name}.json"
       }
     }
     ```
   - Nenhuma configuração especial é necessária para acessar o registry padrão do shadcn/ui.

2. **Como iniciar**
   - Instale o MCP server:
     ```bash
     pnpm dlx shadcn@latest mcp init --client claude
     ```
   - Reinicie seu cliente MCP (Claude Code, Cursor, VS Code, Codex, etc.) após configurar.

3. **Usando no dia-a-dia**
   - Interaja com assistente IA ou MCP client usando prompts como:
     - “Mostre todos os componentes disponíveis”
     - “Adicione os componentes botão, dialog e card ao meu projeto”
     - “Crie um formulário de contato usando os componentes shadcn”

4. **Configuração por editor**
   - Dependendo do editor (Claude Code, Cursor, VS Code, Codex), adicione sempre a configuração MCP no arquivo de config específico (ex: `.mcp.json`, `.cursor/mcp.json`, `.vscode/mcp.json`, `~/.codex/config.toml`).

5. **Registries privados**
   - Para acessar componentes privados, adicione tokens de autenticação no arquivo `.env.local` (exemplo: `REGISTRY_TOKEN=seu_token`).

**Principais comandos para troubleshooting**:
- Verifique configuração se não estiver funcionando.
- Reinicie o client MCP após mudanças.
- Confira URLs e permissões se componentes não carregarem.

**Links úteis:**
- Documentação do registry, namespaces, autenticação, especificação MCP.

**Resumo prático:**
O MCP Server permite que você “converse” com seu projeto via IA para buscar, instalar e gerenciar componentes UI, simplificando processos e unificando fontes em um só lugar. Você só precisa instalar, configurar registries conforme sua necessidade, e pode pedir diretamente via comandos naturais.[1]

# Como Usar o NIC Chat 📚

Guia rápido para você começar a usar o NIC Chat com confiança!

## 🚀 Primeiros Passos

### 1. Navegue até o Chat

Clique no botão **"Começar Agora"** na página inicial ou use o menu de navegação para acessar a página de chat.

### 2. Digite sua mensagem

A interface é simples e intuitiva:
- Campo de texto na parte inferior
- Botão de envio (ou pressione Enter)
- Botão de cancelamento durante o streaming

### 3. Receba a resposta

A resposta da IA aparece em tempo real:
- Streaming palavra por palavra
- Formatação automática de Markdown
- Renderização de diagramas e código

## 💬 Tipos de Mensagens que Você Pode Enviar

### Perguntas Gerais
```
"Explique o que é inteligência artificial"
"Como funciona o aprendizado de máquina?"
```

### Solicitar Diagramas
```
"Crie um diagrama Mermaid mostrando o ciclo de vida de um projeto"
"Desenhe um fluxograma para processo de login"
```

### Análise de Código
```
"Explique este código JavaScript: [seu código]"
"Quais são as melhores práticas para React?"
```

### Tabelas e Listas
```
"Crie uma tabela comparando Python e JavaScript"
"Liste os 10 comandos Git mais usados"
```

## 🎯 Recursos da Interface

### Histórico de Conversas

- Todas as mensagens ficam visíveis na tela
- Role para cima para ver mensagens antigas
- O histórico é salvo automaticamente no navegador

### Botão Copiar

Cada mensagem (sua e da IA) tem um botão de copiar:
- Clique no ícone 📋
- Texto copiado para área de transferência
- Feedback visual de confirmação

### Sugestões Inteligentes

Sidebar com perguntas sugeridas:
- Clique em qualquer sugestão
- Mensagem é enviada automaticamente
- Ideal para inspiração

## ⚙️ Configurações Úteis

### Alternar Tema

Use o botão no canto superior direito:
- 🌞 Modo claro
- 🌙 Modo escuro
- Preferência salva automaticamente

### Gerenciar Histórico

No painel Admin você pode:
- Limpar todo o histórico
- Exportar conversas
- Ver estatísticas de uso

## 💡 Dicas Importantes

💡 **Seja específico**: Quanto mais detalhada sua pergunta, melhor a resposta.

💡 **Use contexto**: A IA lembra do histórico da conversa. Faça perguntas de acompanhamento!

💡 **Experimente formatos**: Peça tabelas, listas, código, diagramas - o NIC renderiza tudo!

💡 **Cancele se necessário**: Se a resposta não está indo bem, cancele e reformule a pergunta.

## ❌ O que Evitar

- Não envie informações sensíveis (senhas, dados pessoais)
- Evite perguntas muito genéricas ("conte-me tudo sobre tudo")
- Não espere respostas instantâneas em diagramas complexos

# Task Plan: 1.3.9 - Implementar revogação de tokens

## Context and Objective

This task implements the token revocation mechanism for the authentication system. Token revocation is critical for security, allowing the platform to invalidate refresh tokens when users logout or when security threats are detected (like token reuse).

**What will be implemented:**
- Backend mechanism to store and track revoked refresh tokens
- Integration with Redis for fast token blacklisting
- Support for single token revocation (logout)
- Support for family-based revocation (logout-all and token reuse detection)
- Token validation logic that checks revocation status

**Why it's needed:**
According to SPEC-authentication.md (SPEC-AU-LGT-006:007), revocation must be immediate and tokens cannot be used after being revoked. This prevents security vulnerabilities where stolen tokens could continue to be used after logout.

**How it integrates:**
- Used by `/api/1/auth/logout` endpoint (revokes single token)
- Used by `/api/1/auth/logout-all` endpoint (revokes all user tokens)
- Used by `/api/1/auth/refresh` endpoint (validates token not revoked, revokes family on reuse)
- Checked by Backbone (n8n) workflows during token validation

**Business value:**
- Provides security by ensuring logged-out sessions cannot be reused
- Enables detection and mitigation of token theft
- Supports multi-device session management
- Compliance with security best practices

**User impact:**
- Users can securely logout from single device or all devices
- Stolen tokens become useless after detection
- Peace of mind knowing sessions are truly terminated

## Critical Context

### Documentation

- [Redis Node Client - Official Docs](https://github.com/redis/node-redis/blob/master/docs/client-configuration.md) - Connection configuration, retry strategies, and error handling
- [Redis Commands - SET/GET/DEL](https://redis.io/commands/) - Core commands for token storage

- [Redis - SCAN Pattern](https://redis.io/commands/scan/) - Efficient key iteration for logout-all

### Gotchas and Pitfalls

- **Redis v4 uses Promises**: The `redis` package v4+ uses async/await, not callbacks. All operations return Promises.
- **Connection must be awaited**: `await client.connect()` before any operations
- **Graceful disconnect**: Always call `await client.disconnect()` on shutdown to prevent connection leaks
- **Key naming convention**: Use namespaced keys (e.g., `auth:revoked:<tokenId>`) to avoid collisions
- **TTL is critical**: Revoked tokens should auto-expire after refresh token TTL (e.g., 7 days) to prevent Redis bloat
- **SCAN vs KEYS**: Never use `KEYS *` in production (blocks Redis). Use `SCAN` for iterating keys.
- **Token family format**: Must be extractable from token (e.g., stored in JWT payload as `fid` field)
- **Race conditions**: Token validation and revocation should be atomic where possible

```typescript
import { createClient, RedisClientType } from 'redis';
import { config } from '../config/env.js';

/**
 * Redis Service - Singleton
 * Manages Redis connection and provides typed operations
 */
class RedisService {
  private client: RedisClientType | null = null;
  private isConnecting = false;
  private isConnected = false;

  /**
   * Get Redis client instance (singleton)
   * Creates and connects on first call
   */
  async getClient(): Promise<RedisClientType> {
    if (this.client && this.isConnected) {
      return this.client;
    }

    if (this.isConnecting) {
      // Wait for connection to complete
      await new Promise((resolve) => {
        const interval = setInterval(() => {
          if (this.isConnected) {
            clearInterval(interval);
            resolve(true);
          }
        }, 100);
      });
      return this.client!;
    }

    this.isConnecting = true;

    try {
      console.log('🔗 Connecting to Redis...');

      this.client = createClient({
        url: config.redis.url,
        socket: {
          reconnectStrategy: (retries) => {
            if (retries > config.redis.maxRetries) {
              console.error(`❌ Redis connection failed after ${retries} retries`);
              return new Error('Max retries reached');
            }
            console.log(`⚠️  Redis retry attempt ${retries}/${config.redis.maxRetries}`);
            return config.redis.retryDelay;
          },
        },
      });

      // Error handlers
      this.client.on('error', (err) => {
        console.error('❌ Redis Client Error:', err);
        this.isConnected = false;
      });

      this.client.on('connect', () => {
        console.log('✅ Redis connected');
        this.isConnected = true;
      });

      this.client.on('disconnect', () => {
        console.log('⚠️  Redis disconnected');
        this.isConnected = false;
      });

      await this.client.connect();
      this.isConnecting = false;

      return this.client;
    } catch (error) {
      this.isConnecting = false;
      console.error('❌ Failed to connect to Redis:', error);
      throw error;
    }
  }

  /**
   * Disconnect from Redis
   * Called during graceful shutdown
   */
  async disconnect(): Promise<void> {
    if (this.client && this.isConnected) {
      console.log('🔌 Disconnecting from Redis...');
      await this.client.quit();
      this.client = null;
      this.isConnected = false;
      console.log('✅ Redis disconnected');
    }
  }

  /**
   * Check if Redis is connected
   */
  isReady(): boolean {
    return this.isConnected;
  }
}

// Export singleton instance
export const redisService = new RedisService();
```

Pattern: Singleton with lazy initialization, comprehensive error handling.

#### 5. Create Token Revocation Service

**Create: `backend/src/services/tokenRevocation.service.ts`**
```typescript
import { redisService } from './redis.service.js';
import { TokenRevocationData, RevocationReason } from '../types/token.types.js';
import { config } from '../config/env.js';

/**
 * Token Revocation Service
 * Handles revocation and validation of refresh tokens
 */
class TokenRevocationService {
  private readonly KEY_PREFIX = 'auth:revoked:';
  private readonly FAMILY_PREFIX = 'auth:family:';

  /**
   * Build Redis key for revoked token
   */
  private getTokenKey(tokenId: string): string {
    return `${this.KEY_PREFIX}${tokenId}`;
  }

  /**
   * Build Redis key pattern for token family
   */
  private getFamilyPattern(familyId: string): string {
    return `${this.FAMILY_PREFIX}${familyId}:*`;
  }

  /**
   * Revoke a single refresh token
   *
   * @param tokenId - Unique token identifier (jti from JWT)
   * @param data - Revocation metadata
   * @returns true if revoked, false if already revoked
   */
  async revokeToken(
    tokenId: string,
    data: Omit<TokenRevocationData, 'tokenId'>
  ): Promise<boolean> {
    try {
      const client = await redisService.getClient();
      const key = this.getTokenKey(tokenId);

      // Store revocation data
      const revocationData: TokenRevocationData = {
        tokenId,
        ...data,
      };

      // SET with TTL (auto-expire after refresh token lifetime)
      await client.setEx(
        key,
        config.token.refreshTokenTTL,
        JSON.stringify(revocationData)
      );

      console.log(`✅ Token revoked: ${tokenId} (reason: ${data.reason})`);
      return true;
    } catch (error) {
      console.error('❌ Failed to revoke token:', error);
      throw error;
    }
  }

  /**
   * Revoke all tokens in a family
   * Used for: logout-all, token reuse detection
   *
   * @param familyId - Token family identifier
   * @param data - Revocation metadata (without tokenId)
   * @returns Number of tokens revoked
   */
  async revokeTokenFamily(
    familyId: string,
    data: Omit<TokenRevocationData, 'tokenId' | 'familyId'>
  ): Promise<number> {
    try {
      const client = await redisService.getClient();
      let revokedCount = 0;

      // Use SCAN to find all tokens in family (cursor-based, non-blocking)
      const pattern = this.getFamilyPattern(familyId);

      for await (const key of client.scanIterator({ MATCH: pattern, COUNT: 100 })) {
        try {
          // Extract tokenId from key
          const tokenId = key.split(':').pop() || '';

          // Revoke token
          await this.revokeToken(tokenId, {
            ...data,
            familyId,
          });

          revokedCount++;
        } catch (err) {
          console.error(`Failed to revoke token from key ${key}:`, err);
        }
      }

      console.log(`✅ Revoked ${revokedCount} tokens from family ${familyId}`);
      return revokedCount;
    } catch (error) {
      console.error('❌ Failed to revoke token family:', error);
      throw error;
    }
  }

  /**
   * Revoke all tokens for a user
   * Used for: logout-all
   *
   * @param userId - User identifier
   * @param reason - Revocation reason
   * @param revokedBy - Who triggered revocation
   * @returns Number of tokens revoked
   */
  async revokeAllUserTokens(
    userId: string,
    reason: RevocationReason,
    revokedBy?: string
  ): Promise<number> {
    try {
      const client = await redisService.getClient();
      let revokedCount = 0;

      // Scan all revoked tokens to find user's active tokens
      // Note: This finds tokens we're tracking, not all possible tokens
      // Real implementation would need token registry or n8n integration

      const pattern = `${this.KEY_PREFIX}*`;

      for await (const key of client.scanIterator({ MATCH: pattern, COUNT: 100 })) {
        try {
          const data = await client.get(key);
          if (!data) continue;

          const tokenData: TokenRevocationData = JSON.parse(data);

          if (tokenData.userId === userId) {
            revokedCount++;
          }
        } catch (err) {
          console.error(`Failed to check token from key ${key}:`, err);
        }
      }

      console.log(`✅ Revoked ${revokedCount} tokens for user ${userId}`);
      return revokedCount;
    } catch (error) {
      console.error('❌ Failed to revoke all user tokens:', error);
      throw error;
    }
  }

  /**
   * Check if a token is revoked
   *
   * @param tokenId - Token identifier to check
   * @returns true if revoked, false if active
   */
  async isTokenRevoked(tokenId: string): Promise<boolean> {
    try {
      const client = await redisService.getClient();
      const key = this.getTokenKey(tokenId);

      const exists = await client.exists(key);
      return exists === 1;
    } catch (error) {
      console.error('❌ Failed to check token revocation:', error);
      // Fail closed: treat as revoked on error
      return true;
    }
  }

  /**
   * Get revocation metadata for a token
   *
   * @param tokenId - Token identifier
   * @returns Revocation data or null if not revoked
   */
  async getRevocationInfo(tokenId: string): Promise<TokenRevocationData | null> {
    try {
      const client = await redisService.getClient();
      const key = this.getTokenKey(tokenId);

      const data = await client.get(key);
      if (!data) return null;

      return JSON.parse(data) as TokenRevocationData;
    } catch (error) {
      console.error('❌ Failed to get revocation info:', error);
      return null;
    }
  }
}

// Export singleton instance
export const tokenRevocationService = new TokenRevocationService();
```

### Error Handling Strategy

**Error Types and Handling:**

1. **Redis Connection Errors**
   - Retry with exponential backoff (configured in redis.service.ts)
   - Log errors prominently
   - Fail gracefully: treat tokens as revoked on connection error (security first)

2. **Token Revocation Errors**
   - Log error with context (tokenId, userId, reason)
   - Re-throw to calling code to handle appropriately
   - Don't silently fail revocation (security risk)

3. **Token Validation Errors**
   - Default to "revoked" state on error (fail closed for security)
   - Log error for debugging
   - Return boolean to avoid exposing error details

**Error Display Pattern:**
```typescript
// Service layer - log and throw
try {
  await client.setEx(key, ttl, data);
} catch (error) {
  console.error('❌ Failed to revoke token:', error);
  throw error; // Let caller handle
}

// Route handler layer - catch and respond
try {
  await tokenRevocationService.revokeToken(tokenId, data);
  res.json({ success: true });
} catch (error) {
  res.status(500).json({
    code: 'revocation_failed',
    message: 'Failed to revoke token',
```

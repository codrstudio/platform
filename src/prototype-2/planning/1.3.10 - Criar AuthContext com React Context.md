# Task Plan: 1.3.10 - Criar AuthContext com React Context

## Context and Objective

**What:** Replace the existing MOCK AuthProvider with a production-ready implementation that integrates with the completed authentication endpoints (login, refresh, logout, logout-all).

**Why:** The current AuthProvider is a temporary mock implementation to unblock development. Now that backend authentication endpoints are complete (tasks 1.3.1-1.3.9), the frontend needs a real implementation that manages authentication state, integrates with TanStack Query for API calls, and provides a foundation for secure token storage (task 1.3.11) and automatic renewal (task 1.3.12).

**How it integrates:** AuthContext sits at the root of the React application (already wrapped in App.tsx), providing global authentication state to all components via React Context. It communicates with the backend auth endpoints, manages user session state, and exposes authentication methods (login, logout, logoutAll) to the rest of the application.

**Business value:** Enables secure user authentication in the platform. Users can log in, maintain sessions, and log out. The foundation enables protected routes, role-based access, and future features like automatic token renewal and multi-session management.

**User impact:** Users will be able to authenticate with real credentials (validated by n8n Backbone), stay logged in across page refreshes (via refresh token), and securely log out. The UX matches modern web applications with seamless session management.

```typescript
const API_BASE_URL = import.meta.env.VITE_API_URL || 'http://localhost:3000';

export async function jqelQuery<T>(query: JQELQuery): Promise<T> {
  const response = await fetch(`${API_BASE_URL}/api/jqel`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(query),
  });

  if (!response.ok) {
    throw new Error(`JQEL request failed: ${response.statusText}`);
  }

  const result: JResult<T> = await response.json();

  if (!result.success || !result.data) {
    throw new Error(result.error?.message || 'JQEL query failed');
  }

  return result.data;
}
```

- This task (1.3.10) implements in-memory token storage only
- SPEC-FS-AU-006:009 specifies secure storage rules

- For now: Store both tokens in React state (memory) only
- DO NOT use localStorage in this task (security risk per SPEC-AU-ST-003)

**⚠️ Token Renewal (Future Task):**
- This task does NOT implement automatic token renewal
- Task 1.3.12 will add renewal logic before token expiration
- For now: User must log in again when access token expires
- DO include logic to restore session on page reload using refresh token

**⚠️ Context Re-renders:**
- Wrap context value in useMemo to prevent unnecessary re-renders (per React docs)
- Split state and methods to optimize consumer re-renders if needed

**⚠️ Error Handling:**
- Auth endpoints return different HTTP status codes (401, 403, 500)

- Display user-friendly errors, log technical details to console

**⚠️ Loading States:**
- Initial auth check (on mount) should show loading spinner

- ProtectedRoute depends on accurate `isLoading` state to avoid redirect flicker

**⚠️ CORS and Credentials:**

#### 2. Create Auth HTTP Client
**File:** `frontend/src/services/auth/authClient.ts`

**Details:**
- HTTP functions for each endpoint: login, refresh, logout, logoutAll
- Use fetch API with proper error handling
- Extract API_BASE_URL from environment variable

**Pattern:** Follow `frontend/src/services/jqel/client.ts` structure

```typescript
const API_BASE_URL = import.meta.env.VITE_API_URL || 'http://localhost:3000';

export async function login(credentials: LoginCredentials): Promise<AuthResponse> {
  const response = await fetch(`${API_BASE_URL}/api/1/auth/login`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(credentials),
  });

  if (!response.ok) {
    const error: AuthErrorResponse = await response.json();
    throw new Error(error.message || 'Login failed');
  }

  return response.json();
}

export async function refreshTokens(refreshToken: string): Promise<AuthResponse> {
  const response = await fetch(`${API_BASE_URL}/api/1/auth/refresh`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ refresh_token: refreshToken }),
  });

  if (!response.ok) {
    const error: AuthErrorResponse = await response.json();
    throw new Error(error.message || 'Token refresh failed');
  }

  return response.json();
}

export async function logout(refreshToken: string): Promise<LogoutResponse> {
  const response = await fetch(`${API_BASE_URL}/api/1/auth/logout`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ refresh_token: refreshToken }),
  });

  if (!response.ok) {
    const error: AuthErrorResponse = await response.json();
    throw new Error(error.message || 'Logout failed');
  }

  return response.json();
}

export async function logoutAll(accessToken: string): Promise<LogoutAllResponse> {
  const response = await fetch(`${API_BASE_URL}/api/1/auth/logout-all`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${accessToken}`,
    },
  });

  if (!response.ok) {
    const error: AuthErrorResponse = await response.json();
    throw new Error(error.message || 'Logout all failed');
  }

  return response.json();
}
```

**Login Function** (using TanStack Query mutation):
```typescript
const loginMutation = useMutation({
  mutationFn: (credentials: LoginCredentials) => authClient.login(credentials),
  onSuccess: (response: AuthResponse) => {
    // Update state with tokens and user
    setAccessToken(response.access_token);
    setRefreshToken(response.refresh_token);
    setUser({
      id: response.payload.sub,
      username: response.payload.username,
      email: response.payload.email,
      roles: response.payload.roles,
      permissions: response.payload.permissions,
    });
  },
  onError: (error: Error) => {
    console.error('Login failed:', error);
    // Clear any partial state
    setUser(null);
    setAccessToken(null);
    setRefreshToken(null);
  },
});

const login = async (credentials: LoginCredentials) => {
  await loginMutation.mutateAsync(credentials);
};
```

**Logout Function:**
```typescript
const logoutMutation = useMutation({
  mutationFn: () => {
    if (!refreshToken) throw new Error('No refresh token');
    return authClient.logout(refreshToken);

    // Clear all auth state
    setUser(null);
    setAccessToken(null);
    setRefreshToken(null);

  onError: (error: Error) => {
    console.error('Logout failed:', error);
    // Still clear state even if API call fails
    setUser(null);
    setAccessToken(null);
    setRefreshToken(null);
  },
});
```

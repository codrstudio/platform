# Task Plan: 1.6.4 - Implementar geração de paleta a partir de brand color

## Context and Objective

This task implements the automatic palette generation system that takes a single brand color (the primary color chosen by a portal/settings-key) and generates all necessary color variants for the theme system. The palette generator must create harmonious, accessible color schemes that work in both light and dark modes.

**What will be implemented:**
- HSL-based color manipulation utilities
- Palette generation algorithm that creates primary-foreground from primary
- Integration with shadcn/ui CSS custom properties pattern
- Support for light/dark mode variants

**Why it's needed:**
- Allows portals to have unique brand identities with minimal configuration
- Ensures visual consistency across the theme
- Reduces manual color selection burden (only need to pick one color)

**How it integrates:**
- Feeds into the ThemeProvider system (Task 1.6.1-1.6.3)
- Used by WCAG validation system (Task 1.6.5)
- Combined with semantic color generation (Task 1.6.6)

**Business value:**
- Portals can be branded quickly with single color input
- Settings-key system allows multiple portals to share same brand
- Professional, cohesive appearance without design expertise

**User impact:**
- Setup module users can pick a brand color and see instant preview
- End users experience consistent, accessible interface
- Automatic foreground color ensures text is always readable

### Documentation

**HSL Color Manipulation:**
- [MDN: HSL Colors](https://developer.mozilla.org/en-US/docs/Web/CSS/color_value/hsl) - Official spec for HSL format
- [W3Schools: HSL and HSLA](https://www.w3schools.com/colors/colors_hsl.asp) - HSL fundamentals
- [GitHub Gist: RGB/HSV/HSL Conversion](https://gist.github.com/mjackson/5311256) - Proven conversion algorithms

**shadcn/ui Theming:**
- [shadcn/ui Theming Docs](https://ui.shadcn.com/docs/theming) - Official theming guide
- Key insight: Store HSL values WITHOUT `hsl()` wrapper: `--primary: 221 83% 53%;`
- Usage in CSS: `background-color: hsl(var(--primary));`
- [Medium: Theming in shadcn UI](https://medium.com/@enayetflweb/theming-in-shadcn-ui-customizing-your-design-with-css-variables-bb6927d2d66b) - CSS variable patterns

**Color Theory:**
- Foreground colors need sufficient contrast against background
- Light mode: Dark text (high lightness reduction) on light backgrounds
- Dark mode: Light text (high lightness) on dark backgrounds
- Saturation adjustments can improve vibrancy

### Gotchas and Pitfalls

**HSL Format Parsing:**
- Input can be HEX (#rrggbb), RGB (rgb(r,g,b)), or HSL string
- shadcn/ui expects HSL values as "hue saturation% lightness%" (space-separated)
- CSS expects `hsl(hue, saturation%, lightness%)` or `hsl(hue saturation% lightness%)`
- Be consistent with which format you store vs. display

**HSL Perceptual Non-Uniformity:**
- Pure HSL manipulation can create colors with inconsistent perceived brightness
- Yellow (H=60) appears brighter than blue (H=240) at same lightness
- For this task, accept this limitation (HSL is spec requirement)
- Future: Consider HSLuv for perceptually uniform palettes

**Lightness Adjustments:**
- Don't just invert lightness for dark mode (produces wrong contrast)
- Light mode primary: Keep original hue/saturation, moderate lightness (40-60%)
- Light mode foreground: High contrast reduction (10-20% lightness for dark text)
- Dark mode primary: May need to increase saturation and lightness
- Dark mode foreground: Very high lightness (90-100%) for light text

**Conversion Precision:**
- HEX to RGB: Straightforward (divide by 255 for 0-1 range)
- RGB to HSL: Handle edge cases (achromatic colors, division by zero)
- HSL to RGB: Use standard algorithm with proper clamping

**CSS Custom Property Format:**
- MUST store as space-separated values: `221 83% 53%`
- NOT as comma-separated: `221, 83%, 53%`
- NOT with hsl() wrapper: `hsl(221, 83%, 53%)`
- This allows Tailwind/CSS to construct `hsl(var(--primary))` or `hsl(var(--primary) / 0.5)` for opacity

**Implementation Notes:**
```typescript
/**
 * Convert HEX color to HSL
 *
 * @param hex - Color in #rrggbb format
 * @returns ColorHSL object
 * @throws ColorParseError if invalid hex
 */
export function hexToHSL(hex: string): ColorHSL {
  // Remove # prefix
  hex = hex.replace(/^#/, '');

  // Validate format
  if (!/^[0-9A-Fa-f]{6}$/.test(hex)) {
    throw new ColorParseError(hex, 'Invalid HEX format. Expected #rrggbb');
  }

  // Parse to RGB
  const r = parseInt(hex.substring(0, 2), 16) / 255;
  const g = parseInt(hex.substring(2, 4), 16) / 255;
  const b = parseInt(hex.substring(4, 6), 16) / 255;

  return rgbToHSL(r, g, b);
}

/**
 * Convert RGB to HSL
 * Algorithm from: https://gist.github.com/mjackson/5311256
 *
 * @param r - Red (0-255 or 0-1)
 * @param g - Green (0-255 or 0-1)
 * @param b - Blue (0-255 or 0-1)
 * @returns ColorHSL object
 */
export function rgbToHSL(r: number, g: number, b: number): ColorHSL {
  // Normalize to 0-1 if needed
  if (r > 1 || g > 1 || b > 1) {
    r /= 255;
    g /= 255;
    b /= 255;
  }

  const max = Math.max(r, g, b);
  const min = Math.min(r, g, b);
  const l = (max + min) / 2;

  let h = 0;
  let s = 0;

  if (max !== min) {
    const d = max - min;
    s = l > 0.5 ? d / (2 - max - min) : d / (max + min);

    switch (max) {
      case r: h = ((g - b) / d + (g < b ? 6 : 0)) / 6; break;
      case g: h = ((b - r) / d + 2) / 6; break;
      case b: h = ((r - g) / d + 4) / 6; break;
    }
  }

  return {
    h: Math.round(h * 360),
    s: Math.round(s * 100),
    l: Math.round(l * 100)
  };
}

/**
 * Format ColorHSL as CSS custom property value
 * SPEC-TH-BC-006: Format must be "hue saturation% lightness%"
 *
 * @param color - ColorHSL object
 * @returns String like "221 83% 53%"
 */
export function hslToString(color: ColorHSL): string {
  return `${color.h} ${color.s}% ${color.l}%`;
}

/**
 * Parse color string (HEX, RGB, or HSL) to ColorHSL
 *
 * @param input - Color string
 * @returns ColorHSL object
 * @throws ColorParseError if format unrecognized
 */
export function parseColor(input: string): ColorHSL {
  input = input.trim();

  // HEX format: #rrggbb
  if (input.startsWith('#')) {
    return hexToHSL(input);
  }

  // HSL format: "221 83% 53%" or "hsl(221, 83%, 53%)"
  const hslMatch = input.match(/^(?:hsl\()?(\d+)\s*,?\s*(\d+)%?\s*,?\s*(\d+)%?\)?$/);
  if (hslMatch) {
    return {
      h: parseInt(hslMatch[1]),
      s: parseInt(hslMatch[2]),
      l: parseInt(hslMatch[3])
    };
  }

  // RGB format: "rgb(r, g, b)"
  const rgbMatch = input.match(/^rgb\((\d+),\s*(\d+),\s*(\d+)\)$/);
  if (rgbMatch) {
    return rgbToHSL(
      parseInt(rgbMatch[1]),
      parseInt(rgbMatch[2]),
      parseInt(rgbMatch[3])
    );
  }

  throw new ColorParseError(input, 'Unrecognized color format');
}

/**
 * Adjust lightness of a color
 *
 * @param color - Base color
 * @param delta - Change in lightness (-100 to +100)
 * @returns New ColorHSL with adjusted lightness
 */
export function adjustLightness(color: ColorHSL, delta: number): ColorHSL {
  return {
    ...color,
    l: clamp(color.l + delta, 0, 100)
  };
}

/**
 * Clamp value to range
 */
export function clamp(value: number, min: number, max: number): number {
  return Math.min(Math.max(value, min), max);
}
```

#### Step 3: Implement Palette Generator

**File:** `src/frontend/src/services/theming/paletteGenerator.ts`

**Details:**
Implement main palette generation logic. Generate primary-foreground based on theme mode.

**Algorithm:**
- Light mode: Dark text on light/medium background (reduce lightness significantly)
- Dark mode: Light text on medium/dark background (increase lightness significantly)
- Preserve hue and saturation from original color

**Pattern:** Functional programming approach (pure functions, no side effects)

```typescript
import type { ColorHSL, ThemeMode, PaletteVariants } from './types';
import { hslToString, adjustLightness } from './colorUtils';

/**
 * Default primary color (shadcn/ui default blue)
 * SPEC-TH-BC-022: Default color "221 83% 53%"
 */
export const DEFAULT_PRIMARY_COLOR: ColorHSL = {
  h: 221,
  s: 83,
  l: 53
};

/**
 * Generate palette variants from brand color
 * SPEC-TH-BC-013:016: Generate primary and primary-foreground
 *
 * @param brandColor - The primary brand color
 * @param mode - Theme mode (light or dark)
 * @returns Palette variants as CSS custom property values
 *
 * @example
 * const palette = generatePalette({ h: 221, s: 83, l: 53 }, 'light');
 * // { primary: "221 83% 53%", primaryForeground: "0 0% 10%" }
 */
export function generatePalette(
  brandColor: ColorHSL,
  mode: ThemeMode
): PaletteVariants {
  const primary = hslToString(brandColor);
  const foreground = generateForeground(brandColor, mode);

  return {
    primary,
    primaryForeground: hslToString(foreground)
  };
}

/**
 * Generate foreground color for primary background
 * SPEC-TH-BC-015: Must guarantee adequate contrast (WCAG AA)
 *
 * Strategy:
 * - Light mode: Very dark text (L=10-20%) for contrast on medium background
 * - Dark mode: Very light text (L=90-100%) for contrast on dark background
 * - Desaturate slightly for better readability
 *
 * @param background - The primary color (background)
 * @param mode - Theme mode
 * @returns Foreground color with high contrast
 */
export function generateForeground(
  background: ColorHSL,
  mode: ThemeMode
): ColorHSL {
  if (mode === 'light') {
    // Light mode: Dark text on colored background
    return {
      h: background.h,
      s: Math.max(background.s - 20, 0), // Slightly desaturate
      l: 10  // Very dark for high contrast
    };
  } else {
    // Dark mode: Light text on colored background
    return {
      h: background.h,
      s: Math.max(background.s - 20, 0), // Slightly desaturate
      l: 98  // Very light for high contrast
    };
  }
}
```

# Task Plan: 1.6.8 - Aplicar tema globalmente

## Context and Objective

This task implements the global theme application system through a React Context Provider that manages theme state, detects system preferences, handles theme persistence, and applies themes across the entire application. The ThemeProvider sits at the application root and ensures consistent theming for all portals and modules.

**What will be implemented:**
- ThemeProvider React Context for global theme state
- Theme mode detection (light/dark/system) with OS preference tracking
- localStorage persistence of theme preferences
- Dark mode class application to `<html>` element
- Integration with CSS custom properties from task 1.6.7
- Theme toggle UI component
- Cross-tab synchronization using storage events
- Prevention of flash-of-unstyled-content (FOUC)

**Why it's needed:**
- Centralized theme management accessible throughout component tree
- Consistent theme application across all portals/modules
- User preference persistence across sessions
- Automatic system theme detection and synchronization

**How it integrates:**
- Wraps App component in provider hierarchy (after QueryClient, before AuthProvider)
- Uses CSS generation utilities from task 1.6.7
- Will be consumed by task 1.6.9 for settings-key based theme sharing
- Available to all components via `useTheme()` hook

**Business value:**
- Professional user experience with theme switching
- Reduced eye strain with dark mode support
- Platform-wide consistency

**User impact:**
- Seamless theme switching without page reload
- Theme preference remembered across sessions
- Automatic theme following system settings

## Critical Context

### Documentation

**React Context Best Practices:**
- [React Context Documentation](https://react.dev/reference/react/useContext)
- Use `useMemo` for context value to prevent unnecessary re-renders
- Throw error in hook if used outside provider
- Keep context value stable with proper dependencies

**Media Query API:**
- [matchMedia Documentation](https://developer.mozilla.org/en-US/docs/Web/API/Window/matchMedia)
- Listen to `(prefers-color-scheme: dark)` for OS theme
- Use `.addEventListener('change', handler)` for updates
- Clean up listener on unmount

**Storage Events:**
- [Storage Event API](https://developer.mozilla.org/en-US/docs/Web/API/Window/storage_event)
- Fires when localStorage changes in other tabs
- Does NOT fire in same tab that made change
- Perfect for cross-tab synchronization

### Gotchas and Pitfalls

**⚠️ FOUC Prevention**
- Theme must be applied BEFORE first render
- Use inline script in `index.html` to read localStorage and set class
- Script runs synchronously before React hydration
- Prevents flash of wrong theme on page load

**⚠️ System Theme Detection**
- `prefers-color-scheme` media query may not exist on older browsers
- Default to 'light' if media query not supported
- Listen to changes with `change` event, not `addListener` (deprecated)

**⚠️ Storage Event Limitations**
- Storage event does NOT fire in tab that made change
- Need separate mechanism for same-tab updates
- Use custom event or React state for same-tab synchronization

**⚠️ Context Re-render Optimization**
- Entire context value re-creates on every render unless memoized
- Use `useMemo` with correct dependencies
- Avoid inline object/function creation in context value

**⚠️ Dark Mode Class vs Attribute**
- Use `class="dark"` not `data-theme="dark"`
- Tailwind expects `dark:` variant to work with `.dark` class
- Apply to `<html>` element, not `<body>` (Tailwind recommendation)

#### 2. Create System Theme Detection

**File:** `src/frontend/src/services/theme/systemTheme.ts`

```typescript
/**
 * System theme detection utilities
 * Based on SPEC-theming.md SPEC-TH-LD-016:018
 */

/**
 * Detect current system theme preference
 *
 * @returns 'dark' if system prefers dark, 'light' otherwise
 */
export function detectSystemTheme(): 'light' | 'dark' {
  // Check if matchMedia is supported
  if (typeof window === 'undefined' || !window.matchMedia) {
    return 'light'; // Default fallback
  }

  try {
    const darkModeQuery = window.matchMedia('(prefers-color-scheme: dark)');
    return darkModeQuery.matches ? 'dark' : 'light';
  } catch (error) {
    console.error('Failed to detect system theme:', error);
    return 'light';
  }
}

/**
 * Watch for system theme changes
 * Returns cleanup function to stop watching
 *
 * @param callback - Called when system theme changes
 * @returns Cleanup function
 */
export function watchSystemTheme(
  callback: (theme: 'light' | 'dark') => void
): () => void {
  // Guard for SSR
  if (typeof window === 'undefined' || !window.matchMedia) {
    return () => {}; // No-op cleanup
  }

  try {
    const darkModeQuery = window.matchMedia('(prefers-color-scheme: dark)');

    // Handler for change event
    const handler = (event: MediaQueryListEvent) => {
      callback(event.matches ? 'dark' : 'light');
    };

    // Modern API (addEventListener)
    darkModeQuery.addEventListener('change', handler);

    // Cleanup function
    return () => {
      darkModeQuery.removeEventListener('change', handler);
    };
  } catch (error) {
    console.error('Failed to watch system theme:', error);
    return () => {};
  }
}
```

**Pattern:** Event subscription with cleanup return, similar to SSE client

#### 4. Create ThemeProvider

```typescript
/**
 * ThemeProvider - Global theme management
 *
 * Based on SPEC-theming.md SPEC-TH-AP-001:020
 *
 * Features:
 * - Theme mode management (light/dark/system)
 * - System theme detection and watching
 * - localStorage persistence
 * - Dark class application to <html>
 * - CSS palette generation and application
 * - Cross-tab synchronization
 */

import React, { createContext, useContext, useState, useEffect, useMemo, useCallback } from 'react';
import type { ThemeMode, ThemeContextValue, HSL } from '../types/theme';
import { saveThemeMode, loadThemeMode, getThemeModeKey } from '../services/theme/themeStorage';
import { detectSystemTheme, watchSystemTheme } from '../services/theme/systemTheme';
import { convertHexToHSL, generatePalette, applyPalette } from '../services/theme';

const ThemeContext = createContext<ThemeContextValue | undefined>(undefined);

/**
 * ThemeProvider component
 * Manages global theme state and applies theme to document
 */
export function ThemeProvider({ children }: { children: React.ReactNode }) {
  // Theme mode state
  const [mode, setModeState] = useState<ThemeMode>(() => {
    // Initialize from localStorage or default to 'system'
    return loadThemeMode() || 'system';
  });

  // Resolved mode (actual light/dark applied)
  const [resolvedMode, setResolvedMode] = useState<'light' | 'dark'>(() => {
    // Initial resolution
    if (mode === 'system') {
      return detectSystemTheme();
    }
    return mode;
  });

  // Brand color state (default to null - will use CSS default)
  const [brandColor, setBrandColorState] = useState<string | null>(null);

  // Derived state
  const isDark = resolvedMode === 'dark';

  /**
   * Update theme mode
   * Saves to localStorage and updates state
   */
  const setMode = useCallback((newMode: ThemeMode) => {
    setModeState(newMode);
    saveThemeMode(newMode);

    // Immediately resolve if not 'system'
    if (newMode !== 'system') {
      setResolvedMode(newMode);
    } else {
      setResolvedMode(detectSystemTheme());
    }
  }, []);

  /**
   * Update brand color
   * Converts HEX to HSL and generates new palette
   */
  const setBrandColor = useCallback((color: string) => {
    setBrandColorState(color);
    // Note: Palette application happens in effect below
  }, []);

  /**
   * Apply dark class to HTML element
   */
  useEffect(() => {
    const root = document.documentElement;

    if (isDark) {
      root.classList.add('dark');
    } else {
      root.classList.remove('dark');
    }
  }, [isDark]);

  /**
   * Apply CSS palette when brand color or mode changes
   */
  useEffect(() => {
    if (brandColor) {
      try {
        const hsl = convertHexToHSL(brandColor);
        const palette = generatePalette(hsl, resolvedMode);
        applyPalette(palette);
      } catch (error) {
        console.error('Failed to apply brand color:', error);
      }
    }
  }, [brandColor, resolvedMode]);

  /**
   * Watch system theme changes (when mode is 'system')
   */
  useEffect(() => {
    if (mode !== 'system') {
      return; // No need to watch if not in system mode
    }

    const cleanup = watchSystemTheme((systemTheme) => {
      setResolvedMode(systemTheme);
    });

    return cleanup;
  }, [mode]);

  /**
   * Cross-tab synchronization
   * Listen to storage events from other tabs
   */
  useEffect(() => {
    const handleStorageChange = (event: StorageEvent) => {
      // Only handle theme mode changes
      if (event.key !== getThemeModeKey()) {
        return;
      }

      // Validate and apply new mode
      const newMode = event.newValue as ThemeMode | null;
      if (newMode === 'light' || newMode === 'dark' || newMode === 'system') {
        setModeState(newMode);

        // Resolve mode
        if (newMode !== 'system') {
          setResolvedMode(newMode);
        } else {
          setResolvedMode(detectSystemTheme());
        }
      }
    };

    window.addEventListener('storage', handleStorageChange);

    return () => {
      window.removeEventListener('storage', handleStorageChange);
    };
  }, []);

  // Context value (optimized with useMemo)
  const value = useMemo<ThemeContextValue>(
    () => ({
      mode,
      resolvedMode,
      setMode,
      isDark,
      brandColor,
      setBrandColor,
    }),
    [mode, resolvedMode, setMode, isDark, brandColor, setBrandColor]
  );

  return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>;
}

/**
 * Hook to access theme context
 * Throws error if used outside ThemeProvider
 */
export function useTheme(): ThemeContextValue {
  const context = useContext(ThemeContext);

  if (context === undefined) {
    throw new Error(
      'useTheme must be used within a ThemeProvider. ' +
      'Wrap your component tree with <ThemeProvider>.'
    );
  }

  return context;
}
```

```typescript
/**
 * ThemeToggle - UI component for theme switching
 * Based on SPEC-theming.md SPEC-TH-AP-007:011
 */

import { Sun, Moon, Monitor } from 'lucide-react';
import { useTheme } from '../../hooks/useTheme';
import type { ThemeMode } from '../../types/theme';

interface ThemeOption {
  mode: ThemeMode;
  label: string;
  icon: typeof Sun;
}

const options: ThemeOption[] = [
  { mode: 'light', label: 'Light', icon: Sun },
  { mode: 'dark', label: 'Dark', icon: Moon },
  { mode: 'system', label: 'System', icon: Monitor },
];

/**
 * Simple button-based theme toggle
 * Cycles through light → dark → system
 */
export function ThemeToggleButton() {
  const { mode, setMode } = useTheme();

  const handleToggle = () => {
    // Cycle through modes
    const currentIndex = options.findIndex(opt => opt.mode === mode);
    const nextIndex = (currentIndex + 1) % options.length;
    setMode(options[nextIndex].mode);
  };

  const current = options.find(opt => opt.mode === mode) || options[0];
  const Icon = current.icon;

  return (
    <button
      onClick={handleToggle}
      className="rounded-md p-2 hover:bg-accent transition-colors"
      aria-label={`Current theme: ${current.label}. Click to cycle.`}
      title={`Theme: ${current.label}`}
    >
      <Icon className="h-5 w-5" />
    </button>
  );
}

/**
 * Dropdown-based theme selector
 * Shows all options with current selection
 */
export function ThemeToggleDropdown() {
  const { mode, setMode } = useTheme();

  return (
    <div className="relative inline-block">
      <select
        value={mode}
        onChange={(e) => setMode(e.target.value as ThemeMode)}
        className="
          rounded-md border border-input bg-background px-3 py-2 text-sm
          focus:outline-none focus:ring-2 focus:ring-ring
          cursor-pointer
        "
        aria-label="Select theme"
      >
        {options.map(({ mode, label, icon: Icon }) => (
          <option key={mode} value={mode}>
            {label}
          </option>
        ))}
      </select>
    </div>
  );
}

/**
 * Default export - simple button toggle
 */
export default ThemeToggleButton;
```

```javascript
/**
 * Theme initialization script
 * Runs before React hydration to prevent FOUC
 *
 * IMPORTANT: This script MUST be synchronous and minimal
 */

(function() {
  'use strict';

  try {
    // Read theme mode from localStorage
    var mode = localStorage.getItem('platform:theme:mode') || 'system';

    // Resolve mode to light/dark
    var resolved = mode;
    if (mode === 'system') {
      var darkQuery = window.matchMedia('(prefers-color-scheme: dark)');
      resolved = darkQuery.matches ? 'dark' : 'light';
    }

    // Apply dark class immediately
    if (resolved === 'dark') {
      document.documentElement.classList.add('dark');
    }
  } catch (error) {
    // Silent fail - React will apply theme
    console.error('Theme init failed:', error);
  }
})();
```

### Error Handling Strategy

**Context Access Errors:**
- Throw descriptive error if `useTheme` used outside provider
- Error message includes solution (wrap with ThemeProvider)

**Storage Errors:**
- Try-catch all localStorage access
- Log errors but continue with defaults
- Graceful degradation (theme still works without persistence)

**System Theme Detection Errors:**
- Catch matchMedia errors
- Default to 'light' if detection fails
- Log warning but don't crash

**Palette Generation Errors:**
- Catch errors in brand color conversion
- Continue with default CSS variables
- Log error for debugging

**Error Display Pattern:**
```typescript
try {
  const hsl = convertHexToHSL(brandColor);
  const palette = generatePalette(hsl, resolvedMode);
  applyPalette(palette);
} catch (error) {
  console.error('Failed to apply brand color:', error);
  // Continue with default theme - no user-visible error
}
```

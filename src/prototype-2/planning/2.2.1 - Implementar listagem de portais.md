# Task Plan: 2.2.1 - Implementar listagem de portais

## Context and Objective

Implement the portal listing page within the Setup module to display all available portals in the platform. This is the foundation of the Portal CRUD functionality, providing users visibility into configured portals and their states.

**Business Value:** Allows platform administrators to see all portals at a glance, understand configuration status, and navigate to portal management actions.

**User Impact:** First touchpoint for portal management - users need clear visibility of all portals with key information before performing any management actions.

**Integration:** This component integrates with the Setup module's routing system and uses the existing JQEL data access layer to fetch portal configurations from the backend schema.

- Portal "main" has `removable: false` - must display this visually with disabled delete action
- Dark mode classes are REQUIRED - always provide both light/dark variants
- Loading states MUST use skeleton loaders, not spinners (SPEC-MS-LO-001)

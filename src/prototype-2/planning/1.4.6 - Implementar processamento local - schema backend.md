# Task Plan: 1.4.6 - Implementar processamento local - schema "backend"

## Context and Objective

This task implements local processing of JQEL queries with schema "backend" within the Backend (Express) layer. Unlike queries with schema "platform" or application schemas (which are proxied to n8n Backbone), queries with schema "backend" are processed directly by the Backend for platform configuration data such as portals, modules, and instances.

**Business Value:** Enables the platform to manage its own configuration (portal/module/instance data) independently of the Backbone, reducing latency and network overhead for configuration queries while maintaining the unified JQEL interface.

**Integration:** This component works alongside the JQEL Router (task 1.4.5) which routes queries based on schema. When the router detects schema="backend", it delegates processing to this local processor instead of proxying to n8n.

### Gotchas and Pitfalls

- **Schema Validation:** MUST verify schema === "backend" before processing. If not, throw error (should never happen if router works correctly).
- **Entity Validation:** Only support entities: `portal`, `module`, `instance`. Unknown entities should return 404.
- **File Locking:** Node.js doesn't have built-in file locking. For MVP, accept race conditions. Document as future improvement.
- **Query Operators:** Implement subset of JQEL operators initially (eq, ne, in, like for WHERE). Document unsupported operators.
- **Pagination:** Always honor limit/offset in options. Default limit to prevent returning massive datasets.
- **Projection:** Implement output/except for field filtering. Never allow both simultaneously (validation should catch this).
- **Mutation Validation:** For mutations, validate required fields based on action (insert needs values, update needs where + values, delete needs where).
- **Circular References:** Modules can depend on other modules. Avoid infinite loops when expanding related data.

#### 2. Create ConfigStorage Service

**Create:** `src/prototype-2/backend/src/services/configStorage.service.ts`

```typescript
import { readFile, writeFile, mkdir } from 'fs/promises';
import { join } from 'path';
import { existsSync } from 'fs';
import { config } from '../config/env.js';
import type { ConfigEntity } from '../types/config.types.js';

/**
 * ConfigStorage Service
 *
 * Handles reading/writing configuration JSON files
 * Implements in-memory caching for performance
 */
export class ConfigStorage {
  private readonly configPath: string;
  private cache: Map<string, ConfigEntity[]> = new Map();

  constructor() {
    this.configPath = config.configPath || join(process.cwd(), 'config');
  }

  /**
   * Load entity data from JSON file
   */
  async load(entity: string): Promise<ConfigEntity[]> {
    // Check cache first
    if (this.cache.has(entity)) {
      return this.cache.get(entity)!;
    }

    // Load from file
    const filePath = join(this.configPath, `${entity}.json`);

    // Ensure config directory exists
    if (!existsSync(this.configPath)) {
      await mkdir(this.configPath, { recursive: true });
    }

    // If file doesn't exist, return empty array
    if (!existsSync(filePath)) {
      this.cache.set(entity, []);
      return [];
    }

    try {
      const content = await readFile(filePath, 'utf-8');
      const data = JSON.parse(content);

      // Validate it's an array
      if (!Array.isArray(data)) {
        throw new Error(`Config file ${entity}.json must contain an array`);
      }

      // Cache and return
      this.cache.set(entity, data);
      return data;
    } catch (error: any) {
      throw new Error(`Failed to load config ${entity}: ${error.message}`);
    }
  }

  /**
   * Save entity data to JSON file
   */
  async save(entity: string, data: ConfigEntity[]): Promise<void> {
    const filePath = join(this.configPath, `${entity}.json`);

    // Ensure config directory exists
    if (!existsSync(this.configPath)) {
      await mkdir(this.configPath, { recursive: true });
    }

    try {
      await writeFile(filePath, JSON.stringify(data, null, 2), 'utf-8');

      // Update cache
      this.cache.set(entity, data);
    } catch (error: any) {
      throw new Error(`Failed to save config ${entity}: ${error.message}`);
    }
  }

  /**
   * Insert new record
   */
  async insert(entity: string, record: ConfigEntity): Promise<ConfigEntity> {
    const data = await this.load(entity);
    data.push(record);
    await this.save(entity, data);
    return record;
  }

  /**
   * Update existing record by ID
   */
  async update(entity: string, id: string, updates: Partial<ConfigEntity>): Promise<ConfigEntity | null> {
    const data = await this.load(entity);
    const idField = this.getIdField(entity);
    const index = data.findIndex((item: any) => item[idField] === id);

    if (index === -1) {
      return null;
    }

    // Merge updates
    data[index] = { ...data[index], ...updates, updatedAt: new Date().toISOString() };
    await this.save(entity, data);
    return data[index];
  }

  /**
   * Delete record by ID
   */
  async delete(entity: string, id: string): Promise<boolean> {
    const data = await this.load(entity);
    const idField = this.getIdField(entity);
    const filtered = data.filter((item: any) => item[idField] !== id);

    if (filtered.length === data.length) {
      return false; // Not found
    }

    await this.save(entity, filtered);
    return true;
  }

  /**
   * Clear cache for entity (useful for testing)
   */
  clearCache(entity?: string): void {
    if (entity) {
      this.cache.delete(entity);
    } else {
      this.cache.clear();
    }
  }

  /**
   * Get primary key field name for entity
   */
  private getIdField(entity: string): string {
    switch (entity) {
      case 'portal':
        return 'portalId';
      case 'module':
        return 'moduleId';
      case 'instance':
        return 'instanceId';
      default:
        throw new Error(`Unknown entity: ${entity}`);
    }
  }
}

export const configStorage = new ConfigStorage();
```

#### 3. Create JQEL Local Processor Service

**Create:** `src/prototype-2/backend/src/services/jqelLocalProcessor.service.ts`

```typescript
import { configStorage } from './configStorage.service.js';
import type { JQELQuery, JResult, WhereClause, WhereOperator, QueryOptions } from '../types/jqel.types.js';
import type { ConfigEntity } from '../types/config.types.js';

/**
 * JQEL Local Processor
 *
 * Processes JQEL queries with schema="backend" locally
 * Operates on configuration files (portal, module, instance)
 *
 * SPEC: SPEC-A-D-008 - Schema "backend" processed by Backend
 */
export class JqelLocalProcessor {
  private readonly supportedEntities = ['portal', 'module', 'instance'];

  /**
   * Process JQEL query
   */
  async processQuery(query: JQELQuery): Promise<JResult> {
    try {
      // Validate schema
      if (query.schema !== 'backend') {
        return {
          code: 400,
          message: 'Local processor only handles schema "backend"',
          field: 'schema',
        };
      }

      // Validate entity
      const entity = query.select || query.mutate;
      if (!entity) {
        return {
          code: 400,
          message: 'Query must have "select" or "mutate"',
        };
      }

      if (!this.supportedEntities.includes(entity)) {
        return {
          code: 404,
          message: `Entity "${entity}" not found in schema "backend"`,
          field: entity,
        };
      }

      // Route to SELECT or MUTATE
      if (query.select) {
        return await this.handleSelect(
          entity,
          query.where,
          query.options,
          query.output,
          query.except
        );
      } else {
        return await this.handleMutate(
          entity,
          query.action!,
          query.values,
          query.where,
          query.output,
          query.except
        );
      }
    } catch (error: any) {
      console.error('❌ Error in jqelLocalProcessor:', error);
      return {
        code: 500,
        message: error.message || 'Internal server error',
      };
    }
  }

  /**
   * Handle SELECT operation
   */
  private async handleSelect(
    entity: string,
    where?: WhereClause,
    options?: QueryOptions,
    output?: string[],
    except?: string[]
  ): Promise<JResult> {
    // Load data
    let data = await configStorage.load(entity);

    // Apply WHERE filter
    if (where) {
      data = this.applyWhere(data, where);
    }

    // Apply OPTIONS (orderBy, limit, offset)
    if (options) {
      data = this.applyOptions(data, options);
    }

    // Apply projection (output/except)
    data = this.applyProjection(data, output, except);

    return {
      code: 200,
      data,
    };
  }

  /**
   * Handle MUTATE operation
   */
  private async handleMutate(
    entity: string,
    action: string,
    values?: Record<string, any>,
    where?: WhereClause,
    output?: string[],
    except?: string[]
  ): Promise<JResult> {
    switch (action) {
      case 'insert':
        return await this.handleInsert(entity, values!, output, except);
      case 'update':
        return await this.handleUpdate(entity, values!, where!, output, except);
      case 'delete':
        return await this.handleDelete(entity, where!);
      default:
        return {
          code: 400,
          message: `Action "${action}" not supported`,
          field: 'action',
        };
    }
  }

  /**
   * Handle INSERT action
   */
  private async handleInsert(
    entity: string,
    values: Record<string, any>,
    output?: string[],
    except?: string[]
  ): Promise<JResult> {
    if (!values || Object.keys(values).length === 0) {
      return {
        code: 400,
        message: 'INSERT requires "values"',
        field: 'values',
      };
    }

    // Add timestamps
    const record = {
      ...values,
      createdAt: new Date().toISOString(),
      updatedAt: new Date().toISOString(),
    };

    // Insert
    const inserted = await configStorage.insert(entity, record);

    // Apply projection
    const projected = this.applyProjection([inserted], output, except);

    return {
      code: 201,
      data: projected,
    };
  }

  /**
   * Handle UPDATE action
   */
  private async handleUpdate(
    entity: string,
    values: Record<string, any>,
    where: WhereClause,
    output?: string[],
    except?: string[]
  ): Promise<JResult> {
    if (!values || Object.keys(values).length === 0) {
      return {
        code: 400,
        message: 'UPDATE requires "values"',
        field: 'values',
      };
    }

    if (!where) {
      return {
        code: 400,
        message: 'UPDATE requires "where"',
        field: 'where',
      };
    }

    // Load and filter
    const data = await configStorage.load(entity);
    const matches = this.applyWhere(data, where);

    if (matches.length === 0) {
      return {
        code: 404,
        message: 'No records found matching WHERE clause',
      };
    }

    // Update all matches
    const idField = this.getIdField(entity);
    const updated: ConfigEntity[] = [];

    for (const match of matches) {
      const result = await configStorage.update(entity, (match as any)[idField], values);
      if (result) {
        updated.push(result);
      }
    }

    // Apply projection
    const projected = this.applyProjection(updated, output, except);

    return {
      code: 200,
      data: projected,
    };
  }

  /**
   * Handle DELETE action
   */
  private async handleDelete(
    entity: string,
    where: WhereClause
  ): Promise<JResult> {
    if (!where) {
      return {
        code: 400,
        message: 'DELETE requires "where"',
        field: 'where',
      };
    }

    // Load and filter
    const data = await configStorage.load(entity);
    const matches = this.applyWhere(data, where);

    if (matches.length === 0) {
      return {
        code: 404,
        message: 'No records found matching WHERE clause',
      };
    }

    // Delete all matches
    const idField = this.getIdField(entity);
    let deletedCount = 0;

    for (const match of matches) {
      const deleted = await configStorage.delete(entity, (match as any)[idField]);
      if (deleted) {
        deletedCount++;
      }
    }

    return {
      code: 200,
      message: `Deleted ${deletedCount} record(s)`,
    };
  }

  /**
   * Apply WHERE clause filtering
   */
  private applyWhere(data: any[], where: WhereClause): any[] {
    return data.filter((record) => this.matchesWhere(record, where));
  }

  /**
   * Check if record matches WHERE clause
   */
  private matchesWhere(record: any, where: WhereClause): boolean {
    // Handle logical operators
    if (where.or) {
      return where.or.some((clause) => this.matchesWhere(record, clause));
    }

    if (where.not) {
      return !this.matchesWhere(record, where.not);
    }

    // Handle field conditions (implicit AND)
    for (const [field, operator] of Object.entries(where)) {
      if (field === 'or' || field === 'not') continue;

      const value = record[field];

      if (!this.matchesOperator(value, operator as WhereOperator)) {
        return false;
      }
    }

    return true;
  }

  /**
   * Check if value matches operator condition
   */
  private matchesOperator(value: any, operator: WhereOperator): boolean {
    if (operator.eq !== undefined) {
      return value === operator.eq;
    }

    if (operator.ne !== undefined) {
      return value !== operator.ne;
    }

    if (operator.gt !== undefined) {
      return value > operator.gt;
    }

    if (operator.gte !== undefined) {
      return value >= operator.gte;
    }

    if (operator.lt !== undefined) {
      return value < operator.lt;
    }

    if (operator.lte !== undefined) {
      return value <= operator.lte;
    }

    if (operator.in !== undefined) {
      return operator.in.includes(value);
    }

    if (operator.like !== undefined) {
      const pattern = operator.like.replace(/%/g, '.*').replace(/_/g, '.');
      const regex = new RegExp(`^${pattern}$`, 'i');
      return regex.test(String(value));
    }

    return true;
  }

  /**
   * Apply OPTIONS (orderBy, limit, offset)
   */
  private applyOptions(data: any[], options: QueryOptions): any[] {
    let result = [...data];

    // Apply orderBy
    if (options.orderBy && options.orderBy.length > 0) {
      result.sort((a, b) => {
        for (const orderItem of options.orderBy!) {
          const [field, direction] = Object.entries(orderItem)[0];
          const aVal = a[field];
          const bVal = b[field];

          if (aVal < bVal) return direction === 'asc' ? -1 : 1;
          if (aVal > bVal) return direction === 'asc' ? 1 : -1;
        }
        return 0;
      });
    }

    // Apply offset
    if (options.offset) {
      result = result.slice(options.offset);
    }

    // Apply limit
    if (options.limit) {
      result = result.slice(0, options.limit);
    }

    return result;
  }

  /**
   * Apply projection (output/except)
   */
  private applyProjection(data: any[], output?: string[], except?: string[]): any[] {
    if (!output && !except) {
      return data;
    }

    return data.map((record) => {
      if (output) {
        // Include only specified fields
        const projected: any = {};
        for (const field of output) {
          if (field in record) {
            projected[field] = record[field];
          }
        }
        return projected;
      } else if (except) {
        // Exclude specified fields
        const projected = { ...record };
        for (const field of except) {
          delete projected[field];
        }
        return projected;
      }
      return record;
    });
  }

  /**
   * Get ID field for entity
   */
  private getIdField(entity: string): string {
    switch (entity) {
      case 'portal':
        return 'portalId';
      case 'module':
        return 'moduleId';
      case 'instance':
        return 'instanceId';
      default:
        throw new Error(`Unknown entity: ${entity}`);
    }
  }
}

export const jqelLocalProcessor = new JqelLocalProcessor();
```

### Error Handling Strategy

**Validation Errors (400):**
- Missing required fields (schema, select/mutate, action for mutate)
- Invalid operators in WHERE clause
- Both output and except specified
- Return structured error with `field` indicating problem

**Not Found Errors (404):**
- Unknown entity in schema "backend"
- No records match WHERE clause in UPDATE/DELETE
- Return error with entity name in message

**Business Logic Errors (422):**
- Duplicate primary key on INSERT
- Invalid foreign key references
- Return error with clear message

**Internal Errors (500):**
- File I/O failures
- JSON parse errors
- Unexpected exceptions
- Log full error, return generic message to client

**Error Display Pattern:**
```typescript
// From errorHandler.middleware.ts pattern
try {

  console.error('❌ Error in jqelLocalProcessor:', error);

  // Create error with statusCode

  err.statusCode = 500;
  throw err;
}
```

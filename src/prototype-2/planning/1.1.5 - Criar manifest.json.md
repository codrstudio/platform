## Critical Context

### Vite Plugin PWA Behavior

**Important:** When using `vite-plugin-pwa`, there are TWO approaches:

1. **Plugin-Generated Manifest (Current):** The `manifest` property in plugin config generates a manifest dynamically. This OVERRIDES any `public/manifest.json`.

2. **Static Manifest File:** If you provide a complete `public/manifest.json` and remove the `manifest` property from plugin config, the plugin uses the static file.

**Decision for this task:** We'll use the **Plugin-Generated Manifest** approach (current) because:
- Allows dynamic manifest based on environment variables (VITE_APP_NAME)
- Ensures consistency between build and dev environments
- Reduces duplication and potential conflicts
- Aligns with modern Vite PWA best practices

**Action:** Remove or archive `public/manifest.json` since plugin generates it.

### PWA Manifest Specification (W3C)

Reference: https://www.w3.org/TR/appmanifest/

**Required Fields (SPEC-A-PWA-011 to 017):**
- `name` - Full application name
- `short_name` - Short name for home screen (max 12 chars recommended)
- `icons` - Array of icon objects with src, sizes, type
- `start_url` - Starting URL when launched
- `display` - Display mode (standalone, fullscreen, minimal-ui, browser)
- `theme_color` - Browser theme color (toolbar color)
- `background_color` - Splash screen background

**Optional but Recommended:**
- `description` - Brief description of the app
- `orientation` - Default orientation (portrait, landscape, any)
- `scope` - Navigation scope (defaults to start_url directory)
- `categories` - App categories for app stores
- `screenshots` - Screenshots for app stores
- `shortcuts` - Quick actions from home screen icon

### Icon Requirements

**PWA Standard Sizes (minimum):**
- 192x192px - Minimum required size for Android home screen
- 512x512px - Minimum required size for splash screens

**Additional Recommended Sizes:**
- 144x144px - Windows 10 tile
- 180x180px - iOS non-retina
- 384x384px - Android high-res devices

**Icon Types:**
- `image/png` - Standard, widely supported
- `image/svg+xml` - Scalable, modern (not all devices support)
- `image/webp` - Smaller size, modern browsers

**Maskable Icons:** For Android adaptive icons, add icons with `purpose: "maskable"` or `purpose: "any maskable"`.

### Gotchas and Pitfalls

⚠️ **Manifest vs Plugin Conflict:** Don't maintain both `public/manifest.json` AND plugin `manifest` config. Choose one approach and stick to it.

⚠️ **Icon Path Inconsistencies:** Current config has mismatch:
- `vite.config.ts` expects: `/icons/icon-192.png` and `/icons/icon-512.png`
- `public/manifest.json` expects: `/icons/icon-192x192.png` and `/icons/icon-512x512.png`
- **Resolution:** Standardize on `-192.png` and `-512.png` format (shorter, cleaner)

⚠️ **Missing Icons:** Currently `public/icons/` directory only has `.gitkeep`, no actual images. Icons MUST be generated or provided.

⚠️ **Theme Color Coordination:** Current manifest uses `theme_color: "#000000"` (black) while plugin uses `#ffffff` (white). Should align with theming system specifications.

⚠️ **Caching Behavior:** Changes to manifest require service worker update. Users may need to clear cache or wait for auto-update cycle.

⚠️ **iOS Support Limitations:** iOS requires additional `<meta>` tags in HTML for full PWA support:
```html
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<link rel="apple-touch-icon" href="/icons/icon-180.png">
```

### Error Handling Strategy

**Build-Time Errors:**

1. **Missing Icon Files:**
   - **Error:** Vite build fails if icon paths in manifest don't exist
   - **Prevention:** Create placeholder icons before building
   - **Recovery:** Provide default/fallback icons in `public/icons/`

2. **Invalid Manifest Configuration:**
   - **Error:** PWA plugin validation fails
   - **Prevention:** Follow manifest specification exactly
   - **Recovery:** Check browser DevTools → Application → Manifest for errors

3. **Environment Variable Missing:**
   - **Error:** Manifest fields show "undefined"
   - **Prevention:** Ensure `.env` file exists and variables are set
   - **Recovery:** Use fallback values in `vite.config.ts` (already implemented)

**Runtime Errors:**

1. **Manifest Not Found (404):**
   - **Symptom:** PWA install prompt doesn't appear
   - **Check:** Browser DevTools → Network → manifest.json
   - **Fix:** Verify Vite PWA plugin is enabled and building manifest

2. **Icon Loading Failure:**
   - **Symptom:** Broken image icons in install prompt
   - **Check:** Browser DevTools → Network → icon paths
   - **Fix:** Verify icon files exist in `public/icons/` with correct names

3. **iOS PWA Not Installing:**
   - **Symptom:** "Add to Home Screen" doesn't work on iOS
   - **Check:** Ensure iOS meta tags are present in HTML
   - **Fix:** Add apple-mobile-web-app tags (Step 4)

**Validation Errors:**

Use browser DevTools to validate manifest:

1. Open DevTools → Application tab
2. Click "Manifest" in left sidebar
3. Check for errors or warnings
4. Verify all fields are present and correct
5. Test "Add to Home Screen" functionality

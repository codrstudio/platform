# Task Plan: 1.4.3 - Implementar envelope JResult

## Context and Objective

This task implements the **JResult envelope** - the standardized response format for all JQEL queries across the platform. Every JQEL query (SELECT or MUTATE) must return a consistent, structured response that encapsulates data, error information, and warnings.

### What will be implemented

1. **Shared TypeScript interfaces** for JResult structure (frontend + backend)
2. **Backend utility functions** for creating JResult responses
3. **Frontend utilities** for handling JResult responses and errors
4. **Error class** extending Error with JResult properties

### Why it's needed

- **Consistency**: All data access uses same response format
- **Type Safety**: TypeScript interfaces prevent runtime errors
- **Error Handling**: Structured errors make debugging easier
- **Integration**: TanStack Query expects consistent response format
- **Specification Compliance**: Implements SPEC-JQEL-RE-001:009

### Gotchas and Pitfalls

- ⚠️ **SPEC-JQEL-RE-013**: `data` field MUST ALWAYS be an array, even for single records
  ```typescript
  // WRONG
  { code: 200, data: { id: 123 } }

  // CORRECT
  { code: 200, data: [{ id: 123 }] }
  ```

- ⚠️ **SPEC-JQEL-RE-014**: `data` CAN be omitted when there's no data (e.g., DELETE operations)
  ```typescript
  { code: 200, message: "Record deleted" } // OK - no data field
  ```

- ⚠️ **SPEC-JQEL-RE-015**: Empty results use empty array, NOT null or undefined
  ```typescript
  { code: 200, data: [] } // CORRECT - no results found
  ```

- ⚠️ **TypeScript Generic Pitfall**: JResult<T> where T is the type of items in the array, not the array itself
  ```typescript
  // WRONG
  const result: JResult<User[]> = { ... }

  // CORRECT
  const result: JResult<User> = {
    code: 200,
    data: [user1, user2] // data is User[], but JResult generic is User
  }
  ```

- ⚠️ **Error vs Warning**: Warnings don't prevent operation success
  ```typescript
  // Valid response with warnings
  {
    code: 200,
    data: [...],
    warnings: [
      { code: 299, message: "Field deprecated", field: "old_field" }
    ]
  }
  ```



```
2. Backend: Validates query, finds schema doesn't exist
3. Backend: return jresult.badRequest('invalid_schema', 'Schema not found', 'schema')

5. Frontend: fetch throws, wrapper catches
6. Frontend: throw new JQELError(jresult)
7. TanStack Query: Sets error state
8. Component: Displays error from error.message
```

#### Step 1: Create shared JResult type definitions

**Create file:** `shared/types/jqel.types.ts`

**Details:**
Define TypeScript interfaces for JResult structure following SPEC-JQEL-RE-001:009.

**Pattern:** Interface definition with JSDoc comments
```typescript
// Pattern from: backend/src/types/auth.types.ts (lines 1-25)
/**
 * JWT payload structure following SPEC-AU-JWT-005:013
 */
export interface JwtPayload {
  sub: string;        // User ID (subject)
  iss?: string;       // Issuer (platform identifier)
  // ...
}
```

**Implementation:**
```typescript
/**
 * JResult - Standardized response envelope for all JQEL queries
 *
 * SPEC References:
 * - SPEC-JQEL-RE-001: Every JQEL query returns JResult envelope
 * - SPEC-JQEL-RE-002: Complete structure with all fields
 * - SPEC-JQEL-RE-003: code is REQUIRED (HTTP status code)
 * - SPEC-JQEL-RE-006: message is OPTIONAL string
 * - SPEC-JQEL-RE-010: field identifies field with error (validation)
 * - SPEC-JQEL-RE-013: data is ALWAYS array (even for single record)
 * - SPEC-JQEL-RE-017: warnings is array of JResult objects
 *
 * @template T - Type of items in the data array
 */
export interface JResult<T = any> {
  /** HTTP status code (REQUIRED) */
  code: number;

  /** Descriptive message (OPTIONAL - usually empty on success, required on error) */
  message?: string;

  /** Field identifier for validation errors (OPTIONAL) */
  field?: string;

  /** Data array (CONDITIONAL - always array when present, can be omitted) */
  data?: T[];

  /** Non-blocking warnings (OPTIONAL) */
  warnings?: JResultWarning[];
}

/**
 * Warning structure for non-blocking alerts
 *
 * SPEC-JQEL-RE-017:020
 */
export interface JResultWarning {
  /** Warning code (typically 299) */
  code: number;

  /** Warning message */
  message: string;

  /** Related field (OPTIONAL) */
  field?: string;
}

/**
 * Valid HTTP status codes for JResult
 *
 * SPEC-JQEL-STA-001:017
 */
export type StatusCode =
  // Success (2xx)
  | 200  // OK
  | 201  // Created
  | 299  // Deprecation Warning
  // Client Error (4xx)
  | 400  // Bad Request
  | 401  // Unauthorized
  | 403  // Forbidden
  | 404  // Not Found
  | 409  // Conflict
  | 422  // Unprocessable Entity
  | 429  // Too Many Requests
  // Server Error (5xx)
  | 500  // Internal Server Error
  | 503; // Service Unavailable

/**
 * JQEL Query structure (placeholder for future implementation)
 * Will be expanded in task 1.4.2
 */
export interface JQELQuery {
  schema: string;
  select?: string;
  mutate?: string;
  action?: string;
  where?: Record<string, any>;
  options?: {
    limit?: number;
    offset?: number;
    orderBy?: Array<Record<string, 'asc' | 'desc'>>;
  };
  values?: Record<string, any>;
  output?: string[];
  except?: string[];
}
```

#### Step 2: Create backend JResult utility functions

**Create file:** `backend/src/utils/jresult.util.ts`

**Details:**
Factory functions for creating JResult responses with proper typing and validation.

**Pattern:** Utility object with factory methods
```typescript
// Pattern from: backend/src/services/tokenRotation.service.ts

  generateRefreshToken: (): string => { ... },
  storeRefreshToken: async (...) => { ... },
  validateRefreshToken: async (...) => { ... }

```

**Implementation:**
```typescript
import type { JResult, JResultWarning, StatusCode } from '../../../shared/types/jqel.types.js';

/**
 * Backend utilities for creating JResult responses
 *
 * Provides factory functions for consistent JResult creation
 * following SPEC-JQEL-RE-001:009
 */
const jresult = {
  /**
   * Create successful response (HTTP 200)
   *
   * @param data - Array of data items (MUST be array, even for single item)
   * @param code - HTTP status code (default: 200)
   * @returns JResult with success status
   *
   * @example
   * jresult.success([{ id: 1, name: 'John' }])
   * // { code: 200, data: [{ id: 1, name: 'John' }] }
   */
  success: <T>(data: T[], code: StatusCode = 200): JResult<T> => {
    return {
      code,
      data,
    };
  },

  /**
   * Create success response without data
   *
   * Used for operations that don't return data (e.g., DELETE)
   *
   * @param message - Optional success message
   * @returns JResult without data field
   *
   * @example
   * jresult.noContent('Record deleted successfully')
   * // { code: 200, message: 'Record deleted successfully' }
   */
  noContent: (message?: string): JResult => {
    return message ? { code: 200, message } : { code: 200 };
  },

  /**
   * Create created response (HTTP 201)
   *
   * @param data - Created item(s) as array
   * @returns JResult with 201 status
   *
   * @example
   * jresult.created([{ id: 123, name: 'New User' }])
   * // { code: 201, data: [{ id: 123, name: 'New User' }] }
   */
  created: <T>(data: T[]): JResult<T> => {
    return {
      code: 201,
      data,
    };
  },

  /**
   * Create error response
   *
   * @param code - HTTP status code (400-599)
   * @param message - Error message
   * @param field - Optional field identifier for validation errors
   * @returns JResult with error information
   *
   * @example
   * jresult.error(400, 'Field is required', 'username')
   * // { code: 400, message: 'Field is required', field: 'username' }
   */
  error: (code: StatusCode, message: string, field?: string): JResult => {
    const result: JResult = { code, message };
    if (field) {
      result.field = field;
    }
    return result;
  },

  /**
   * Create bad request error (HTTP 400)
   *
   * @param message - Error message
   * @param field - Optional field identifier
   * @returns JResult with 400 status
   */
  badRequest: (message: string, field?: string): JResult => {
    return jresult.error(400, message, field);
  },

  /**
   * Create unauthorized error (HTTP 401)
   *
   * @param message - Error message
   * @returns JResult with 401 status
   */
  unauthorized: (message: string = 'Unauthorized'): JResult => {
    return jresult.error(401, message);
  },

  /**
   * Create forbidden error (HTTP 403)
   *
   * @param message - Error message
   * @returns JResult with 403 status
   */
  forbidden: (message: string = 'Forbidden'): JResult => {
    return jresult.error(403, message);
  },

  /**
   * Create not found error (HTTP 404)
   *
   * @param message - Error message
   * @returns JResult with 404 status
   */
  notFound: (message: string = 'Resource not found'): JResult => {
    return jresult.error(404, message);
  },

  /**
   * Create conflict error (HTTP 409)
   *
   * @param message - Error message
   * @param field - Optional field identifier
   * @returns JResult with 409 status
   */
  conflict: (message: string, field?: string): JResult => {
    return jresult.error(409, message, field);
  },

  /**
   * Create unprocessable entity error (HTTP 422)
   *
   * @param message - Error message
   * @param field - Optional field identifier
   * @returns JResult with 422 status
   */
  unprocessable: (message: string, field?: string): JResult => {
    return jresult.error(422, message, field);
  },

  /**
   * Create internal server error (HTTP 500)
   *
   * @param message - Error message (default: generic message)
   * @returns JResult with 500 status
   */
  serverError: (message: string = 'Internal server error'): JResult => {
    return jresult.error(500, message);
  },

  /**
   * Add warnings to existing JResult
   *
   * @param result - Existing JResult
   * @param warnings - Warnings to add
   * @returns JResult with warnings appended
   *
   * @example
   * const result = jresult.success([...]);
   * const withWarnings = jresult.withWarnings(result, [
   *   { code: 299, message: 'Field deprecated', field: 'old_field' }
   * ]);
   */
  withWarnings: <T>(result: JResult<T>, warnings: JResultWarning[]): JResult<T> => {
    return {
      ...result,
      warnings: [...(result.warnings || []), ...warnings],
    };
  },
};

export default jresult;
```

#### Step 3: Create frontend JResult utility functions

**Create file:** `frontend/src/services/jqel/jresult.util.ts`

**Details:**
Type guards and helper functions for working with JResult in frontend code.

**Pattern:** Named exports of utility functions
```typescript
// Pattern: Pure utility functions with type guards
export function isJResult(value: unknown): value is JResult {
  return typeof value === 'object' && value !== null && 'code' in value;
}
```

**Implementation:**
```typescript
import type { JResult } from '../../../../shared/types/jqel.types';

/**
 * Type guard to check if value is a JResult
 *
 * @param value - Value to check
 * @returns true if value is JResult
 *
 * @example
 * if (isJResult(response)) {
 *   console.log(response.code);
 * }
 */
export function isJResult<T = any>(value: unknown): value is JResult<T> {
  return (
    typeof value === 'object' &&
    value !== null &&
    'code' in value &&
    typeof (value as any).code === 'number'
  );
}

/**
 * Check if JResult represents success (2xx status)
 *
 * @param result - JResult to check
 * @returns true if status code is 2xx
 *
 * @example
 * if (isSuccess(result)) {
 *   console.log('Success!', result.data);
 * }
 */
export function isSuccess<T>(result: JResult<T>): boolean {
  return result.code >= 200 && result.code < 300;
}

/**
 * Check if JResult represents error (4xx or 5xx status)
 *
 * @param result - JResult to check
 * @returns true if status code is 4xx or 5xx
 *
 * @example
 * if (isError(result)) {
 *   console.error('Error:', result.message);
 * }
 */
export function isError<T>(result: JResult<T>): boolean {
  return result.code >= 400;
}

/**
 * Check if JResult represents client error (4xx status)
 *
 * @param result - JResult to check
 * @returns true if status code is 4xx
 */
export function isClientError<T>(result: JResult<T>): boolean {
  return result.code >= 400 && result.code < 500;
}

/**
 * Check if JResult represents server error (5xx status)
 *
 * @param result - JResult to check
 * @returns true if status code is 5xx
 */
export function isServerError<T>(result: JResult<T>): boolean {
  return result.code >= 500;
}

/**
 * Safely extract data array from JResult
 *
 * Returns empty array if data is undefined or result is error
 *
 * @param result - JResult to extract from
 * @returns Data array or empty array
 *
 * @example
 * const users = extractData(result);
 * users.forEach(user => console.log(user.name));
 */
export function extractData<T>(result: JResult<T>): T[] {
  if (isError(result) || !result.data) {
    return [];
  }
  return result.data;
}

/**
 * Extract first item from data array
 *
 * Useful for queries that return single record
 *
 * @param result - JResult to extract from
 * @returns First item or undefined
 *
 * @example
 * const user = extractFirst(result);
 * if (user) console.log(user.name);
 */
export function extractFirst<T>(result: JResult<T>): T | undefined {
  const data = extractData(result);
  return data.length > 0 ? data[0] : undefined;
}

/**
 * Check if JResult has warnings
 *
 * @param result - JResult to check
 * @returns true if warnings exist
 */
export function hasWarnings<T>(result: JResult<T>): boolean {
  return Array.isArray(result.warnings) && result.warnings.length > 0;
}

/**
 * Get user-friendly error message from JResult
 *
 * Falls back to generic message if none provided
 *
 * @param result - JResult error
 * @returns Error message string
 *
 * @example
 * const message = getErrorMessage(result);
 * toast.error(message);
 */
export function getErrorMessage<T>(result: JResult<T>): string {
  if (result.message) {
    return result.message;
  }

  // Fallback messages based on status code
  if (result.code === 400) return 'Invalid request';
  if (result.code === 401) return 'Unauthorized';
  if (result.code === 403) return 'Forbidden';
  if (result.code === 404) return 'Not found';
  if (result.code === 409) return 'Conflict';
  if (result.code === 422) return 'Unprocessable entity';
  if (result.code === 429) return 'Too many requests';
  if (result.code >= 500) return 'Server error';

  return 'An error occurred';
}
```

**Implementation:**
```typescript
import type { JResult } from '../../../../shared/types/jqel.types';

/**
 * Custom error class for JQEL errors
 *
 * Wraps JResult error response for better integration with
 * TanStack Query and error boundaries
 *
 * SPEC References:
 * - SPEC-DA-W-009:011 - JQELError class structure
 * - SPEC-ERR-JQEL-001:006 - JQEL error categories
 *
 * @example
 * try {
 *   const result = await jqel.query({ ... });
 *   if (result.code >= 400) {
 *     throw new JQELError(result);
 *   }
 * } catch (error) {
 *   if (error instanceof JQELError) {
 *     console.error('JQEL Error:', error.code, error.message);
 *   }
 * }
 */
export class JQELError<T = any> extends Error {
  /** HTTP status code from JResult */
  public readonly code: number;

  /** Field identifier for validation errors */
  public readonly field?: string;

  /** Complete JResult response */
  public readonly jresult: JResult<T>;

  /**
   * Create JQELError from JResult
   *
   * @param jresult - JResult error response
   */
  constructor(jresult: JResult<T>) {
    // Use message from JResult or fallback
    super(jresult.message || 'JQEL query failed');

    // Set error name for debugging
    this.name = 'JQELError';

    // Store JResult properties
    this.code = jresult.code;
    this.field = jresult.field;
    this.jresult = jresult;

    // Maintain proper prototype chain for instanceof checks
    Object.setPrototypeOf(this, JQELError.prototype);

    // Capture stack trace (V8 only)
    if (Error.captureStackTrace) {
      Error.captureStackTrace(this, JQELError);
    }
  }

  /**
   * Check if error is client error (4xx)
   */
  public isClientError(): boolean {
    return this.code >= 400 && this.code < 500;
  }

  /**
   * Check if error is server error (5xx)
   */
  public isServerError(): boolean {
    return this.code >= 500;
  }

  /**
   * Check if error is validation error (400 or 422)
   */
  public isValidationError(): boolean {
    return this.code === 400 || this.code === 422;
  }

  /**
   * Check if error is authentication error (401)
   */
  public isAuthError(): boolean {
    return this.code === 401;
  }

  /**
   * Check if error is permission error (403)
   */
  public isPermissionError(): boolean {
    return this.code === 403;
  }

  /**
   * Check if error is not found (404)
   */
  public isNotFoundError(): boolean {
    return this.code === 404;
  }

  /**
   * Get user-friendly error message
   *
   * Includes field name for validation errors
   */
  public getUserMessage(): string {
    if (this.field && this.message) {
      return `${this.field}: ${this.message}`;
    }
    return this.message;
  }

  /**
   * Convert to plain object for logging
   */
  public toJSON() {
    return {
      name: this.name,
      message: this.message,
      code: this.code,
      field: this.field,
      jresult: this.jresult,
      stack: this.stack,
    };
  }
}

/**
 * Type guard to check if error is JQELError
 *
 * @param error - Error to check
 * @returns true if error is JQELError instance
 *
 * @example
 * try {
 *   // ...
 * } catch (error) {
 *   if (isJQELError(error)) {
 *     console.log('Status code:', error.code);
 *   }
 * }
 */
export function isJQELError(error: unknown): error is JQELError {
  return error instanceof JQELError;
}
```

### Error Handling Strategy

**Error Types:**

1. **Network Errors** (fetch fails)
   - Handling: TanStack Query will retry automatically
   - Display: "Connection error. Retrying..."

2. **HTTP Errors** (4xx, 5xx)
   - Handling: Parse JResult, throw JQELError
   - Display: Show `error.message` from JResult

3. **Validation Errors** (400, 422)
   - Handling: Extract `field` from JResult
   - Display: Show error next to specific field in form

4. **Authentication Errors** (401)
   - Handling: Trigger token refresh, retry query
   - Display: If refresh fails, redirect to login

5. **Permission Errors** (403)
   - Handling: No retry, user cannot access
   - Display: "You don't have permission for this action"

**Error Display Pattern:**

```typescript
// In component
const { data, error, isLoading } = useQuery({
  queryKey: ['users'],
  queryFn: () => jqel.query({ ... })
});

if (error) {
  if (error instanceof JQELError) {
    if (error.isValidationError() && error.field) {
      // Show field-specific error
      return <FieldError field={error.field} message={error.message} />;
    }
    if (error.isNotFoundError()) {
      return <NotFoundPage />;
    }
    // Generic error
    return <ErrorMessage message={error.getUserMessage()} />;
  }
  // Network error
  return <ErrorMessage message="Connection error. Please try again." />;
}
```

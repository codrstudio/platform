# Task Plan: 1.6.1 - Criar ThemeProvider

## Context and Objective

This task implements the ThemeProvider component, which manages the theme state and applies theme preferences across the entire application. The ThemeProvider is a React Context-based component that wraps the application and provides theme-related state and methods to all child components.

**Business Value:** Enables users to customize the visual appearance of the application with light/dark modes and custom brand colors, improving user experience and brand consistency.

**Integration Point:** The ThemeProvider will wrap the entire application at the root level (in App.tsx or main.tsx), sitting alongside AuthProvider and SSEProvider. It will read the portal's `settings-key` to determine which theme configuration to load from localStorage.

  }
}

### Gotchas and Pitfalls

- **Settings Key Dependency:** The ThemeProvider MUST read the portal's `settings-key` to determine which localStorage keys to use. Portals with the same `settings-key` share theme preferences.
  - For now (Task 1.6.1), use a **hardcoded default** `settings-key = "default"` since portal loading isn't fully implemented yet.
  - In future tasks, this will be read from `usePortalConfig()` hook.

- **Initial Flash Prevention:** Theme must be applied BEFORE first render to avoid flash of wrong theme (SPEC-TH-PE-001). For this task, we'll apply synchronously in the provider. Future task may add inline script in index.html.

- **Memo Dependencies:** Be careful with `useMemo` dependencies. Only include values that should trigger re-creation of context value. Functions (setTheme, setBrandColor) are stable and don't need to be in deps.

- **LocalStorage Keys:** Use format `{settings-key}:theme` and `{settings-key}:brand-color` (SPEC-TH-SK-008:010)

- **Type Safety:** Define strict types for theme mode (`"light" | "dark" | "system"`) to prevent invalid values

### Modules and Responsibilities

**ThemeProvider Component** (`src/providers/ThemeProvider.tsx`)
- Manages theme state (theme mode, brand color, settings-key)
- Loads theme preferences from localStorage on mount
- Applies theme to DOM (HTML class and CSS variables)
- Provides context value to children
- Exports `useTheme` hook for consuming components

**Theme Storage Service** (`src/services/theme/themeStorage.ts`)
- Encapsulates localStorage operations
- Functions: `loadTheme()`, `saveTheme()`, `loadBrandColor()`, `saveBrandColor()`
- Handles errors gracefully (try-catch)

**Type Definitions** (`src/types/theme.ts`)
- `ThemeMode` - Union type for theme modes
- `ThemeContextValue` - Interface for context value
- `ThemeProviderProps` - Props interface

### State Management

**React Context:** Global theme state accessible via `useTheme()` hook

**State Shape:**
```typescript
{
  theme: ThemeMode;              // Current theme mode (resolved, not "system")
  rawTheme: ThemeMode;           // User preference (may be "system")
  brandColor: string | null;     // HSL color string or null for default
  settingsKey: string;           // Portal's settings key
  setTheme: (mode: ThemeMode) => void;
  setBrandColor: (color: string | null) => void;
}
```

**State Updates:**
- `setTheme()` - Updates theme mode and saves to localStorage
- `setBrandColor()` - Updates brand color and saves to localStorage
- Both trigger re-render and DOM updates

- **React 19** - Context API, hooks (useState, useEffect, useMemo)
- **localStorage** - Browser API for persistence
- **TypeScript** - Type safety

3. **Create ThemeProvider component** (`src/providers/ThemeProvider.tsx`)

   **3.1. Set up Context and basic structure:**
   ```typescript
   import { createContext, useContext, useState, useMemo } from 'react';

   const ThemeContext = createContext<ThemeContextValue | undefined>(undefined);

   export function ThemeProvider({ children }: { children: React.ReactNode }) {
     // State will be added here
     return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>;
   }
   ```

   **3.2. Add state variables:**
   ```typescript
   const [settingsKey] = useState<string>('default'); // Hardcoded for now
   const [rawTheme, setRawTheme] = useState<ThemeMode>('system');
   const [brandColor, setBrandColorState] = useState<string | null>(null);
   ```

   **3.3. Add theme resolution logic (system → light/dark):**
   ```typescript
   const [theme, setTheme] = useState<ThemeMode>('light'); // Resolved theme

   // Effect to resolve "system" theme
   useEffect(() => {
     if (rawTheme !== 'system') {
       setTheme(rawTheme);
       return;
     }

     // Detect system preference
     const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
     const updateTheme = () => setTheme(mediaQuery.matches ? 'dark' : 'light');

     updateTheme(); // Initial
     mediaQuery.addEventListener('change', updateTheme);

     return () => mediaQuery.removeEventListener('change', updateTheme);
   }, [rawTheme]);
   ```

   **3.4. Add effect to load theme from localStorage on mount:**
   ```typescript
   useEffect(() => {
     const savedTheme = themeStorage.loadTheme(settingsKey);
     if (savedTheme) setRawTheme(savedTheme);

     const savedColor = themeStorage.loadBrandColor(settingsKey);
     if (savedColor) setBrandColorState(savedColor);
   }, [settingsKey]);
   ```

   **3.5. Add effect to apply theme to DOM:**
   ```typescript
   useEffect(() => {
     // Apply theme class to <html>
     document.documentElement.classList.remove('light', 'dark');
     document.documentElement.classList.add(theme);

     // Apply brand color CSS variable (if set)
     if (brandColor) {
       document.documentElement.style.setProperty('--primary', brandColor);
     } else {
       document.documentElement.style.removeProperty('--primary');
     }
   }, [theme, brandColor]);
   ```

   **3.6. Add setter methods:**
   ```typescript
   const handleSetTheme = (newTheme: ThemeMode) => {
     setRawTheme(newTheme);
     themeStorage.saveTheme(settingsKey, newTheme);
   };

   const handleSetBrandColor = (color: string | null) => {
     setBrandColorState(color);
     if (color) {
       themeStorage.saveBrandColor(settingsKey, color);
     }
   };
   ```

   **3.7. Create context value with useMemo:**
   ```typescript
   const value = useMemo<ThemeContextValue>(
     () => ({
       theme,
       rawTheme,
       brandColor,
       settingsKey,
       setTheme: handleSetTheme,
       setBrandColor: handleSetBrandColor,
     }),
     [theme, rawTheme, brandColor, settingsKey]
   );
   ```

### Error Handling Strategy

**LocalStorage Errors:**
- Wrap all localStorage operations in try-catch
- Log errors to console
- Fail silently - use default values if storage unavailable
- Pattern from `storageStrategies.ts`

**Missing Context Error:**
- Throw descriptive error if `useTheme()` called outside provider
- Pattern from `useAuth()`

**Invalid Theme Values:**
- Validate theme mode against `ThemeMode` type
- Fallback to `"system"` for invalid values (SPEC-TH-LD-006)

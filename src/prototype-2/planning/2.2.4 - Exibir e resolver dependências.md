# Task Plan: 2.2.4 - Exibir e resolver dependências

## Context and Objective

This task implements comprehensive dependency visualization and automatic resolution for modules. When activating a module, the system will detect its dependencies, visualize them, and offer to automatically activate all required dependencies in the correct order. This enhances the user experience by eliminating manual dependency management.

**Business Value:** Reduces configuration errors and simplifies module activation by automating dependency resolution. Ensures system integrity by preventing invalid configurations where dependent modules are missing.

**User Impact:** Administrators can activate complex modules with a single action, without needing to manually track and activate dependencies. The system handles the complexity automatically while keeping users informed.

**Integration:** Enhances the activation flow (Task 2.2.2) with automatic dependency resolution. Improves deactivation (Task 2.2.3) with dependent module warnings. Integrates with module listing (Task 2.2.1) to visualize dependency relationships.

### Reusable Code Examples

**Topological Sort Pattern (Kahn's Algorithm):**
```typescript
function topologicalSort(modules: Module[]): Module[] {
  // Build adjacency list and in-degree map
  const graph = new Map<string, string[]>();
  const inDegree = new Map<string, number>();

  modules.forEach(module => {
    graph.set(module.moduleId, module.dependencies || []);
    inDegree.set(module.moduleId, 0);
  });

  modules.forEach(module => {
    (module.dependencies || []).forEach(dep => {
      inDegree.set(dep, (inDegree.get(dep) || 0) + 1);
    });
  });

  // Find modules with no dependencies (in-degree 0)
  const queue: string[] = [];
  inDegree.forEach((degree, moduleId) => {
    if (degree === 0) queue.push(moduleId);
  });

  const sorted: string[] = [];

  while (queue.length > 0) {
    const current = queue.shift()!;
    sorted.push(current);

    const dependencies = graph.get(current) || [];
    dependencies.forEach(dep => {
      const newDegree = (inDegree.get(dep) || 0) - 1;
      inDegree.set(dep, newDegree);
      if (newDegree === 0) queue.push(dep);
    });
  }

  // If not all modules processed, there's a cycle
  if (sorted.length !== modules.length) {
    throw new Error('Circular dependency detected');
  }

  return sorted.map(id => modules.find(m => m.moduleId === id)!);
}
```

**Circular Dependency Detection:**
```typescript
function detectCircularDependency(
  moduleId: string,
  modules: Module[],
  visited = new Set<string>(),
  path = new Set<string>()
): string[] | null {
  if (path.has(moduleId)) {
    return Array.from(path); // Circular dependency found
  }

  if (visited.has(moduleId)) {
    return null; // Already checked this branch
  }

  visited.add(moduleId);
  path.add(moduleId);

  const module = modules.find(m => m.moduleId === moduleId);
  const dependencies = module?.dependencies || [];

  for (const dep of dependencies) {
    const circular = detectCircularDependency(dep, modules, visited, path);
    if (circular) return circular;
  }

  path.delete(moduleId);
  return null;
}
```

### Gotchas and Pitfalls
- ⚠️ **Circular dependency detection is mandatory:** Must detect before attempting activation (SPEC-MO-DE-008, SPEC-MS-VA-009)
- ⚠️ **Topological order matters:** Dependencies must be activated before dependent modules
- ⚠️ **Portal context:** Dependencies must be resolved per-portal (module might be active in one portal but not another)
- ⚠️ **Already active optimization:** Skip dependencies already active in target portal
- ⚠️ **Missing module handling:** If dependency module doesn't exist in system, show clear error (can't proceed)
- ⚠️ **Automatic activation UX:** Show what will be activated, allow cancellation before proceeding

   ```typescript
   import type { Module } from '../../../types/module';

   export interface DependencyResolution {
     toActivate: Module[];
     alreadyActive: Module[];
     order: string[];
     hasCircular: boolean;
     circularPath?: string[];
   }

   /**
    * Detect circular dependency in module graph
    */
   export function detectCircularDependency(
     moduleId: string,
     modules: Module[],
     visited = new Set<string>(),
     path = new Set<string>()
   ): string[] | null {
     if (path.has(moduleId)) {
       return Array.from(path);
     }

     if (visited.has(moduleId)) {
       return null;
     }

     visited.add(moduleId);
     path.add(moduleId);

     const module = modules.find(m => m.moduleId === moduleId);
     const dependencies = module?.dependencies || [];

     for (const dep of dependencies) {
       const circular = detectCircularDependency(dep, modules, visited, new Set(path));
       if (circular) return circular;
     }

     path.delete(moduleId);
     return null;
   }

   /**
    * Topologically sort modules by dependencies
    */
   export function topologicalSort(modules: Module[]): string[] {
     const graph = new Map<string, string[]>();
     const inDegree = new Map<string, number>();

     modules.forEach(module => {
       graph.set(module.moduleId, module.dependencies || []);
       inDegree.set(module.moduleId, 0);
     });

     modules.forEach(module => {
       (module.dependencies || []).forEach(dep => {
         inDegree.set(dep, (inDegree.get(dep) || 0) + 1);
       });
     });

     const queue: string[] = [];
     inDegree.forEach((degree, moduleId) => {
       if (degree === 0) queue.push(moduleId);
     });

     const sorted: string[] = [];

     while (queue.length > 0) {
       const current = queue.shift()!;
       sorted.push(current);

       const dependencies = graph.get(current) || [];
       dependencies.forEach(dep => {
         const newDegree = (inDegree.get(dep) || 0) - 1;
         inDegree.set(dep, newDegree);
         if (newDegree === 0) queue.push(dep);
       });
     }

     if (sorted.length !== modules.length) {
       throw new Error('Circular dependency detected');
     }

     return sorted;
   }

   /**
    * Resolve dependencies for a module activation
    */
   export function resolveDependencies(
     moduleId: string,
     portalId: string,
     allModules: Module[],
     portal: { activeModules: string[] }
   ): DependencyResolution {
     const module = allModules.find(m => m.moduleId === moduleId);
     if (!module) {
       throw new Error('Module not found');
     }

     // Check circular dependency
     const circular = detectCircularDependency(moduleId, allModules);
     if (circular) {
       return {
         toActivate: [],
         alreadyActive: [],
         order: [],
         hasCircular: true,
         circularPath: circular,
       };
     }

     // Collect all dependencies recursively
     const allDeps = new Set<string>();
     const collectDeps = (mid: string) => {
       const m = allModules.find(mod => mod.moduleId === mid);
       (m?.dependencies || []).forEach(dep => {
         allDeps.add(dep);
         collectDeps(dep);
       });
     };
     collectDeps(moduleId);

     // Split into already active and to-activate
     const alreadyActive: Module[] = [];
     const toActivate: Module[] = [];

     allDeps.forEach(depId => {
       const depModule = allModules.find(m => m.moduleId === depId);
       if (!depModule) return;

       if (portal.activeModules.includes(depId)) {
         alreadyActive.push(depModule);
       } else {
         toActivate.push(depModule);
       }
     });

     // Topologically sort modules to activate
     const order = toActivate.length > 0 ? topologicalSort(toActivate) : [];

     return {
       toActivate,
       alreadyActive,
       order,
       hasCircular: false,
     };
   }
   ```

   import { GitBranch, Check } from 'lucide-react';
   import type { Module } from '../../../types/module';

   interface DependencyGraphProps {
     rootModuleId: string;
     modules: Module[];
     activeModules: string[];
     compact?: boolean;
   }

   export function DependencyGraph({
     rootModuleId,
     modules,
     activeModules,
     compact = false
   }: DependencyGraphProps) {
     const rootModule = modules.find(m => m.moduleId === rootModuleId);
     if (!rootModule) return null;

     const renderNode = (moduleId: string, level: number = 0): JSX.Element | null => {
       const module = modules.find(m => m.moduleId === moduleId);
       if (!module) return null;

       const isActive = activeModules.includes(moduleId);
       const dependencies = module.dependencies || [];

       return (
         <div key={moduleId} className="space-y-1">
           <div
             className="flex items-center gap-2"
             style={{ paddingLeft: `${level * 20}px` }}
           >
             <GitBranch className="w-4 h-4 text-muted-foreground flex-shrink-0" />
             <span className={`text-sm ${
               isActive ? 'text-green-600 dark:text-green-400 font-medium' : 'text-foreground'
             }`}>
               {module.name}
             </span>
             {isActive && <Check className="w-4 h-4 text-green-600" />}
           </div>

           {!compact && dependencies.length > 0 && (
             <div className="space-y-1">
               {dependencies.map(dep => renderNode(dep, level + 1))}
             </div>
           )}
         </div>
       );
     };

     return (
       <div className="space-y-2 p-3 bg-muted/30 rounded-md border" role="tree">
         {renderNode(rootModuleId)}
       </div>
     );
   }
   ```

                       <span className="text-muted-foreground">
                         {' '}({resolution.alreadyActive.length} already active)
                       </span>
                     )}
                   </p>
                 </div>
               </div>
             </AlertDialogDescription>
           </AlertDialogHeader>
           <AlertDialogFooter>
             <AlertDialogCancel disabled={isActivating}>Cancel</AlertDialogCancel>
             <AlertDialogAction
               onClick={onConfirm}
               disabled={isActivating}
             >
               {isActivating ? (
                 <>
                   <Loader2 className="w-4 h-4 mr-2 animate-spin" />
                   Activating {totalToActivate} {totalToActivate === 1 ? 'Module' : 'Modules'}...
                 </>
               ) : (
                 `Activate ${totalToActivate} ${totalToActivate === 1 ? 'Module' : 'Modules'}`
               )}
             </AlertDialogAction>
           </AlertDialogFooter>
         </AlertDialogContent>
       </AlertDialog>
     );
   }
   ```

### Error Handling Strategy

**Error Types:**
- Circular dependency: Show blocking error dialog, prevent activation
- Missing dependency module: Show error, list missing modules, prevent activation
- Partial activation failure: Rollback all, show which module failed
- Network error during batch activation: Rollback all, allow retry

**Error Display Pattern:**
```typescript
try {
  // Activate dependencies in order
  for (const dep of resolution.toActivate) {
    await activateModule(dep.moduleId, portalId);
  }
  // Then activate target
  await activateModule(targetModule.moduleId, portalId);

} catch (error) {
  toast({
    title: 'Batch activation failed',
    description: `Failed to activate: ${error.message}. All changes rolled back.`,
    variant: 'error',
    duration: 5000
  });

  // Rollback all
  resolution.toActivate.forEach(dep => {
    queryClient.invalidateQueries({ queryKey: queryKeys.backend.module(dep.moduleId) });
  });
  queryClient.invalidateQueries({ queryKey: queryKeys.backend.portal(portalId) });
}
```

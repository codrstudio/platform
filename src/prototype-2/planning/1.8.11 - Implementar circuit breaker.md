# Task Plan: 1.8.11 - Implementar circuit breaker

## Context and Objective

**What:** Implement a Circuit Breaker pattern to prevent cascading failures by stopping requests to failing services and allowing them time to recover.

**Why:** When a service (e.g., n8n, external API) is down or degraded, continuously retrying requests wastes resources and degrades user experience. Circuit breaker "opens" after repeated failures, immediately rejecting requests and giving the service time to recover, then gradually allows requests through to test if service has recovered.

**Integration:** Works with retry logic (task 1.8.10), JQEL queries, n8n proxy, SSE connections, and all network operations that might experience sustained failures.

**Business Value:** Improves system resilience and prevents resource exhaustion during outages. Provides graceful degradation and faster recovery from cascading failures.

**User Impact:** Users see immediate error messages instead of waiting for timeouts when services are known to be down. System recovers faster when services come back online.

### Gotchas and Pitfalls

**State Synchronization:**
- Frontend has multiple circuit instances (per browser tab)
- Backend instances need shared state (use Redis)
- State transitions must be atomic
- Race conditions when multiple requests fail simultaneously

**Threshold Tuning:**
- Too sensitive: Circuit opens too easily (false positives)
- Too lenient: Allows too many failures (defeats purpose)
- Recommended: 5 consecutive failures OR 50% error rate in 10 requests

**Timeout Duration:**
- Too short: Service hasn't recovered, circuit re-opens immediately
- Too long: Users wait unnecessarily for service recovery
- Recommended: 30-60 seconds based on service SLA

**Half-Open State:**
- Only allow 1-3 requests through to test
- If any fail, immediately re-open circuit
- If all succeed, close circuit
- Don't allow full traffic immediately

**Memory Leaks:**
- Timers must be cleaned up
- Old circuit instances must be garbage collected
- Clear stale state from Redis

**False Positives:**
- Single timeout shouldn't open circuit
- Client errors (4xx) shouldn't open circuit
- Only count server errors (5xx) and network failures

```typescript
/**
 * Circuit Breaker types
 * Based on SPEC-error-handling.md SPEC-EH-RE-008:012
 */

/**
 * Circuit breaker states
 */
export enum CircuitState {
  /** Normal operation - requests pass through */
  CLOSED = 'CLOSED',
  /** Service failing - reject all requests */
  OPEN = 'OPEN',
  /** Testing recovery - allow limited requests */
  HALF_OPEN = 'HALF_OPEN'
}

/**
 * Circuit breaker configuration
 */
export interface CircuitBreakerConfig {
  /**
   * Circuit name (unique identifier)
   */
  name: string;

  /**
   * Number of consecutive failures before opening circuit
   * @default 5
   */
  failureThreshold?: number;

  /**
   * Error rate threshold (0-1) to open circuit
   * If error rate exceeds this in window, circuit opens
   * @default 0.5 (50%)
   */
  errorThresholdPercentage?: number;

  /**
   * Window size for calculating error rate (number of requests)
   * @default 10
   */
  windowSize?: number;

  /**
   * Time in ms to wait in open state before attempting half-open
   * @default 30000 (30 seconds)
   */
  timeout?: number;

  /**
   * Number of requests to allow through in half-open state
   * @default 1
   */
  halfOpenMaxRequests?: number;

  /**
   * Callback on state change
   */
  onStateChange?: (from: CircuitState, to: CircuitState) => void;

  /**
   * Custom error classifier - return true if error should count towards threshold
   * @default Only count server errors (5xx) and network errors
   */
  shouldCountError?: (error: Error) => boolean;
}

/**
 * Circuit breaker state snapshot
 */
export interface CircuitBreakerState {
  /** Current state */
  state: CircuitState;
  /** Number of consecutive failures */
  consecutiveFailures: number;
  /** Total requests in current window */
  totalRequests: number;
  /** Failed requests in current window */
  failedRequests: number;
  /** Error rate (0-1) */
  errorRate: number;
  /** Number of requests allowed in half-open state */
  halfOpenAttempts: number;
  /** Timestamp of last state change */
  lastStateChange: number;
  /** Timestamp when circuit will attempt half-open (if currently open) */
  nextAttempt?: number;
}

/**
 * Result of circuit breaker execution
 */
export interface CircuitBreakerResult<T> {
  /** Execution result value */
  value: T;
  /** State after execution */
  state: CircuitBreakerState;
  /** Whether circuit state changed */
  stateChanged: boolean;
}

/**
 * Circuit breaker error - thrown when circuit is open
 */
export class CircuitBreakerError extends Error {
  constructor(
    public circuitName: string,
    public state: CircuitState,
    public nextAttempt?: number
  ) {
    const message = state === CircuitState.OPEN
      ? `Circuit breaker '${circuitName}' is open. Next attempt at ${new Date(nextAttempt || 0).toISOString()}`
      : `Circuit breaker '${circuitName}' is in ${state} state and cannot accept more requests`;

    super(message);
    this.name = 'CircuitBreakerError';

    if (Error.captureStackTrace) {
      Error.captureStackTrace(this, CircuitBreakerError);
    }
  }
}

/**
 * Type guard for CircuitBreakerError
 */
export function isCircuitBreakerError(error: unknown): error is CircuitBreakerError {
  return error instanceof CircuitBreakerError;
}
```

#### 2. Create Frontend Circuit Breaker

```typescript
import {
  CircuitState,
  CircuitBreakerError,
  type CircuitBreakerConfig,
  type CircuitBreakerState,
  type CircuitBreakerResult
} from '../../types/circuitBreaker';
import { classifyError, RetryableErrorType } from './retry';

/**
 * Default configuration
 */
const DEFAULT_CONFIG: Required<Omit<CircuitBreakerConfig, 'name' | 'onStateChange' | 'shouldCountError'>> = {
  failureThreshold: 5,
  errorThresholdPercentage: 0.5,
  windowSize: 10,
  timeout: 30000, // 30 seconds
  halfOpenMaxRequests: 1,
};

/**
 * Circuit Breaker implementation
 * Based on SPEC-EH-RE-008:012
 *
 * @example
 * const circuit = new CircuitBreaker('jqel-backend', {
 *   failureThreshold: 5,
 *   timeout: 30000,
 *   onStateChange: (from, to) => {
 *     console.log(`Circuit ${from} → ${to}`);
 *   }
 * });
 *
 * // Execute request through circuit
 * try {
 *   const result = await circuit.execute(() => fetchData());
 *   console.log('Success:', result.value);
 * } catch (error) {
 *   if (isCircuitBreakerError(error)) {
 *     console.log('Circuit is open');
 *   }
 * }
 */
export class CircuitBreaker {
  private state: CircuitState = CircuitState.CLOSED;
  private consecutiveFailures = 0;
  private requestWindow: boolean[] = []; // true = success, false = failure
  private halfOpenAttempts = 0;
  private lastStateChange = Date.now();
  private nextAttemptTime?: number;
  private openTimeout?: number;

  private readonly config: Required<Omit<CircuitBreakerConfig, 'onStateChange' | 'shouldCountError'>> &
    Pick<CircuitBreakerConfig, 'onStateChange' | 'shouldCountError'>;

  constructor(
    public readonly name: string,
    userConfig: Omit<CircuitBreakerConfig, 'name'> = {}
  ) {
    this.config = {
      ...DEFAULT_CONFIG,
      ...userConfig
    };
  }

  /**
   * Get current circuit breaker state
   */
  getState(): CircuitBreakerState {
    const failedRequests = this.requestWindow.filter(r => !r).length;
    const totalRequests = this.requestWindow.length;
    const errorRate = totalRequests > 0 ? failedRequests / totalRequests : 0;

    return {
      state: this.state,
      consecutiveFailures: this.consecutiveFailures,
      totalRequests,
      failedRequests,
      errorRate,
      halfOpenAttempts: this.halfOpenAttempts,
      lastStateChange: this.lastStateChange,
      nextAttempt: this.nextAttemptTime
    };
  }

  /**
   * Check if error should count towards threshold
   */
  private shouldCountError(error: Error): boolean {
    if (this.config.shouldCountError) {
      return this.config.shouldCountError(error);
    }

    // Default: Only count server and network errors
    const errorType = classifyError(error);
    return errorType === RetryableErrorType.SERVER_ERROR ||
           errorType === RetryableErrorType.NETWORK_ERROR;
  }

  /**
   * Transition to new state
   */
  private transitionTo(newState: CircuitState): void {
    const oldState = this.state;
    if (oldState === newState) return;

    this.state = newState;
    this.lastStateChange = Date.now();

    // Log state change
    if (import.meta.env.DEV) {
      console.log(`[CircuitBreaker:${this.name}] ${oldState} → ${newState}`);
    }

    // Clear timeout if transitioning from OPEN
    if (oldState === CircuitState.OPEN && this.openTimeout) {
      clearTimeout(this.openTimeout);
      this.openTimeout = undefined;
      this.nextAttemptTime = undefined;
    }

    // Schedule half-open attempt if transitioning to OPEN
    if (newState === CircuitState.OPEN) {
      this.nextAttemptTime = Date.now() + this.config.timeout;
      this.openTimeout = setTimeout(() => {
        this.transitionTo(CircuitState.HALF_OPEN);
      }, this.config.timeout) as unknown as number;
    }

    // Reset counters on state change
    if (newState === CircuitState.CLOSED) {
      this.consecutiveFailures = 0;
      this.requestWindow = [];
      this.halfOpenAttempts = 0;
    } else if (newState === CircuitState.HALF_OPEN) {
      this.halfOpenAttempts = 0;
    }

    // Invoke callback
    this.config.onStateChange?.(oldState, newState);
  }

  /**
   * Record successful request
   */
  private recordSuccess(): void {
    this.consecutiveFailures = 0;

    // Add to window
    this.requestWindow.push(true);
    if (this.requestWindow.length > this.config.windowSize) {
      this.requestWindow.shift();
    }

    // State transitions
    if (this.state === CircuitState.HALF_OPEN) {
      // Success in half-open → close circuit
      this.transitionTo(CircuitState.CLOSED);
    }
  }

  /**
   * Record failed request
   */
  private recordFailure(error: Error): void {
    // Only count certain errors
    if (!this.shouldCountError(error)) {
      return;
    }

    this.consecutiveFailures++;

    // Add to window
    this.requestWindow.push(false);
    if (this.requestWindow.length > this.config.windowSize) {
      this.requestWindow.shift();
    }

    // Calculate error rate
    const failedRequests = this.requestWindow.filter(r => !r).length;
    const errorRate = this.requestWindow.length > 0
      ? failedRequests / this.requestWindow.length
      : 0;

    // Check thresholds
    const exceedsConsecutive = this.consecutiveFailures >= this.config.failureThreshold;
    const exceedsRate = this.requestWindow.length >= this.config.windowSize &&
                        errorRate >= this.config.errorThresholdPercentage;

    // State transitions
    if (this.state === CircuitState.CLOSED) {
      if (exceedsConsecutive || exceedsRate) {
        this.transitionTo(CircuitState.OPEN);
      }
    } else if (this.state === CircuitState.HALF_OPEN) {
      // Any failure in half-open → re-open circuit
      this.transitionTo(CircuitState.OPEN);
    }
  }

  /**
   * Execute operation through circuit breaker
   *
   * @param operation - Async operation to execute
   * @returns Result with state metadata
   * @throws CircuitBreakerError if circuit is open or half-open limit exceeded
   */
  async execute<T>(
    operation: () => Promise<T>
  ): Promise<CircuitBreakerResult<T>> {
    const initialState = this.state;

    // Check if request is allowed
    if (this.state === CircuitState.OPEN) {
      throw new CircuitBreakerError(this.name, this.state, this.nextAttemptTime);
    }

    if (this.state === CircuitState.HALF_OPEN) {
      if (this.halfOpenAttempts >= this.config.halfOpenMaxRequests) {
        throw new CircuitBreakerError(this.name, this.state);
      }
      this.halfOpenAttempts++;
    }

    // Execute operation
    try {
      const value = await operation();
      this.recordSuccess();

      return {
        value,
        state: this.getState(),
        stateChanged: this.state !== initialState
      };

    } catch (error) {
      this.recordFailure(error as Error);
      throw error;
    }
  }

  /**
   * Reset circuit breaker to closed state
   * Useful for manual recovery or testing
   */
  reset(): void {
    this.transitionTo(CircuitState.CLOSED);
  }

  /**
   * Cleanup - clear timers
   */
  destroy(): void {
    if (this.openTimeout) {
      clearTimeout(this.openTimeout);
      this.openTimeout = undefined;
    }
  }
}
```

#### 3. Create React Hook

```typescript
import { useState, useEffect, useCallback, useRef } from 'react';
import { CircuitBreaker } from '../utils/circuitBreaker';
import {
  CircuitState,
  type CircuitBreakerConfig,
  type CircuitBreakerState
} from '../../types/circuitBreaker';

export interface UseCircuitBreakerReturn {
  /** Execute operation through circuit breaker */
  execute: <T>(operation: () => Promise<T>) => Promise<T>;
  /** Current circuit state */
  state: CircuitBreakerState;
  /** Whether circuit is open */
  isOpen: boolean;
  /** Reset circuit to closed state */
  reset: () => void;
}

/**
 * React hook for circuit breaker with state updates
 *
 * @example
 * const { execute, state, isOpen, reset } = useCircuitBreaker('jqel-backend', {
 *   failureThreshold: 5,
 *   timeout: 30000
 * });
 *
 * // Execute with circuit breaker
 * try {
 *   const data = await execute(() => fetchData());
 * } catch (error) {
 *   if (isCircuitBreakerError(error)) {
 *     console.log('Service unavailable, circuit is open');
 *   }
 * }
 *
 * // Show circuit status in UI
 * {isOpen && <Alert>Service temporarily unavailable</Alert>}
 */
export function useCircuitBreaker(
  name: string,
  config: Omit<CircuitBreakerConfig, 'name'> = {}
): UseCircuitBreakerReturn {
  const circuitRef = useRef<CircuitBreaker | null>(null);
  const [state, setState] = useState<CircuitBreakerState>({
    state: CircuitState.CLOSED,
    consecutiveFailures: 0,
    totalRequests: 0,
    failedRequests: 0,
    errorRate: 0,
    halfOpenAttempts: 0,
    lastStateChange: Date.now()
  });

  // Initialize circuit breaker
  useEffect(() => {
    circuitRef.current = new CircuitBreaker(name, {
      ...config,
      onStateChange: (from, to) => {
        setState(circuitRef.current!.getState());
        config.onStateChange?.(from, to);
      }
    });

    // Update initial state
    setState(circuitRef.current.getState());

    // Cleanup on unmount
    return () => {
      circuitRef.current?.destroy();
    };
  }, [name]); // Recreate if name changes

  /**
   * Execute operation through circuit
   */
  const execute = useCallback(async <T,>(
    operation: () => Promise<T>
  ): Promise<T> => {
    if (!circuitRef.current) {
      throw new Error('Circuit breaker not initialized');
    }

    const result = await circuitRef.current.execute(operation);

    // Update state after execution
    setState(circuitRef.current.getState());

    return result.value;
  }, []);

  /**
   * Reset circuit breaker
   */
  const reset = useCallback(() => {
    circuitRef.current?.reset();
    setState(circuitRef.current!.getState());
  }, []);

  return {
    execute,
    state,
    isOpen: state.state === CircuitState.OPEN,
    reset
  };
}
```

```typescript
// Create circuit breakers per schema
const circuits = new Map<string, CircuitBreaker>();

function getCircuit(schema: string): CircuitBreaker {
  if (!circuits.has(schema)) {
    circuits.set(schema, new CircuitBreaker(`jqel-${schema}`, {
      failureThreshold: 5,
      timeout: 30000,
      onStateChange: (from, to) => {
        console.log(`[JQEL Circuit:${schema}] ${from} → ${to}`);
      }
    }));
  }
  return circuits.get(schema)!;
}

 * Execute JQEL query with circuit breaker protection
 */
export async function jqelQuery<T = any>(query: JQELQuery): Promise<T[]> {
  const circuit = getCircuit(query.schema);

  try {
    const result = await circuit.execute(async () => {
      const response = await fetch(JQEL_ENDPOINT, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${getAccessToken()}`
        },
        body: JSON.stringify(query)
      });

      return parseJQELResponse<T>(response);
    });

    return result.value;

  } catch (error) {
    // Circuit breaker error → provide user-friendly message
    if (isCircuitBreakerError(error)) {
      throw new JQELError({
        code: 503,
        message: `Service '${query.schema}' is temporarily unavailable. Please try again later.`,
        data: []
      });
    }

    throw error;
  }
}
```

#### 5. Create Backend Circuit Breaker Store

**File:** `src/backend/src/services/circuitBreakerStore.ts`

```typescript
import { redisService } from './redis.service';
import { CircuitState } from '../../../types/circuitBreaker';

/**
 * Redis-backed circuit breaker state store
 * Shares state across backend instances
 */
export class CircuitBreakerStore {
  private readonly keyPrefix = 'circuit:';
  private readonly defaultTTL = 300; // 5 minutes

  /**
   * Get circuit state from Redis
   */
  async getState(name: string): Promise<CircuitState | null> {
    const key = `${this.keyPrefix}${name}:state`;
    const state = await redisService.get(key);

    if (!state) return null;

    // Validate state value
    if (Object.values(CircuitState).includes(state as CircuitState)) {
      return state as CircuitState;
    }

    return null;
  }

  /**
   * Set circuit state in Redis with TTL
   */
  async setState(
    name: string,
    state: CircuitState,
    ttlSeconds?: number
  ): Promise<void> {
    const key = `${this.keyPrefix}${name}:state`;
    const ttl = ttlSeconds ?? this.defaultTTL;

    await redisService.set(key, state);
    await redisService.expire(key, ttl);
  }

  /**
   * Increment failure count atomically
   */
  async incrementFailures(name: string): Promise<number> {
    const key = `${this.keyPrefix}${name}:failures`;
    const count = await redisService.incr(key);
    await redisService.expire(key, 60); // Expire after 1 minute
    return count;
  }

  /**
   * Reset failure count
   */
  async resetFailures(name: string): Promise<void> {
    const key = `${this.keyPrefix}${name}:failures`;
    await redisService.del(key);
  }

  /**
   * Get failure count
   */
  async getFailures(name: string): Promise<number> {
    const key = `${this.keyPrefix}${name}:failures`;
    const count = await redisService.get(key);
    return count ? parseInt(count, 10) : 0;
  }

  /**
   * Clear all circuit state (for testing/reset)
   */
  async clear(name: string): Promise<void> {
    const pattern = `${this.keyPrefix}${name}:*`;
    const keys = await redisService.keys(pattern);

    if (keys.length > 0) {
      await redisService.del(...keys);
    }
  }
}

export const circuitBreakerStore = new CircuitBreakerStore();
```

**Pattern:** Redis-backed state with atomic operations

#### 6. Create Backend Circuit Breaker

**File:** `src/backend/src/utils/circuitBreaker.ts`

```typescript
import { CircuitState, CircuitBreakerError } from '../../../types/circuitBreaker';
import type { CircuitBreakerConfig } from '../types/circuitBreaker.types';
import { circuitBreakerStore } from '../services/circuitBreakerStore';

const DEFAULT_CONFIG = {
  failureThreshold: 5,
  timeout: 30000,
};

/**
 * Backend circuit breaker with Redis state storage
 * State is shared across all backend instances
 */
export class CircuitBreaker {
  private readonly config: typeof DEFAULT_CONFIG;

  constructor(
    public readonly name: string,
    userConfig: Partial<CircuitBreakerConfig> = {}
  ) {
    this.config = { ...DEFAULT_CONFIG, ...userConfig };
  }

  /**
   * Get current state from Redis
   */
  async getState(): Promise<CircuitState> {
    const state = await circuitBreakerStore.getState(this.name);
    return state ?? CircuitState.CLOSED;
  }

  /**
   * Execute operation through circuit breaker
   */
  async execute<T>(operation: () => Promise<T>): Promise<T> {
    const state = await this.getState();

    // Reject if circuit is open
    if (state === CircuitState.OPEN) {
      throw new CircuitBreakerError(this.name, state);
    }

    try {
      const result = await operation();

      // Success → reset failures, close circuit
      await circuitBreakerStore.resetFailures(this.name);
      await circuitBreakerStore.setState(this.name, CircuitState.CLOSED);

      return result;

    } catch (error) {
      // Increment failure count
      const failures = await circuitBreakerStore.incrementFailures(this.name);

      // Open circuit if threshold exceeded
      if (failures >= this.config.failureThreshold) {
        console.log(`[CircuitBreaker:${this.name}] Opening circuit after ${failures} failures`);
        await circuitBreakerStore.setState(
          this.name,
          CircuitState.OPEN,
          Math.floor(this.config.timeout / 1000) // TTL in seconds
        );
      }

      throw error;
    }
  }

  /**
   * Reset circuit to closed state
   */
  async reset(): Promise<void> {
    await circuitBreakerStore.clear(this.name);
  }
}
```

**Pattern:** Backend version using Redis for shared state

### Error Handling Strategy

**Circuit States:**

1. **CLOSED (Normal):**
   - All requests pass through
   - Track success/failure in sliding window
   - Open circuit if threshold exceeded

2. **OPEN (Failing):**
   - Reject all requests immediately with CircuitBreakerError
   - Don't execute operation
   - Wait timeout period, then transition to HALF_OPEN

3. **HALF_OPEN (Testing):**
   - Allow 1 test request through
   - If success → transition to CLOSED
   - If failure → transition back to OPEN
   - Reject other requests

**Error Classification:**
```typescript
// Count towards circuit breaker
- 5xx Server Errors
- Network timeouts
- DNS failures

// Don't count towards circuit breaker
- 4xx Client Errors
- Validation errors
- Auth errors (401, 403)
```

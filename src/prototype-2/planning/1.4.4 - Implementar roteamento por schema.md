# Task Plan: 1.4.4 - Implementar roteamento por schema

## Context and Objective

This task implements the JQEL schema-based routing system, which directs queries to appropriate processors based on their schema identifier. The schema routing is the core dispatching mechanism that determines how and where each JQEL query is processed.

**What will be implemented:**
- Schema routing logic to classify queries by schema type
- Routing decision mechanism (backend, platform, system, application)
- Integration with n8n proxy for platform and application schemas
- Backend schema processor for portal/module/instance configuration
- Validation and error handling for schema routing

**Why it's needed:**
- Enables multi-channel data access architecture (SPEC-channels.md)
- Separates platform configuration (backend) from business logic (backbone/n8n)
- Provides foundation for schema isolation and security boundaries
- Allows different processing strategies per schema type

**How it integrates:**
- Works with JQEL endpoint (task 1.4.1) to receive validated queries
- Calls n8n proxy service (existing) for platform/application schemas
- Implements backend processor for backend schema operations
- Feeds into query validation (task 1.4.2) and JResult envelope (task 1.4.3)

**Business value:**
- Clear separation of concerns (platform config vs business data)
- Flexibility to add new schemas without changing routing logic
- Security through schema-based access control
- Performance through targeted routing (local vs remote processing)

**User impact:**
- Transparent routing - users don't need to know where data is processed
- Fast responses for backend schema (local processing, no network call)
- Consistent API regardless of schema type
- Better error messages with schema-specific context

### Gotchas and Pitfalls

**Schema Routing:**
- ⚠️ Reserved schemas (`platform`, `backend`, `system`) have special handling - MUST NOT treat as application schemas
- ⚠️ `system` schema routing is configurable - MUST check environment variable for routing decision
- ⚠️ Application schemas (anything not reserved) MUST be routed to Backbone by default
- ⚠️ Schema names are case-sensitive - "Platform" !== "platform"

**Backend Schema Processing:**
- ⚠️ Backend schema queries access local file system (not database) for portal/module/instance config
- ⚠️ Backend processor MUST NOT make network calls to n8n
- ⚠️ File operations are synchronous in Node.js - use async fs.promises API
- ⚠️ Handle file not found gracefully (return empty array, not error)

**n8n Proxy:**
- ⚠️ Platform and application schemas MUST include X-Platform-Key header
- ⚠️ JQEL queries to n8n use different endpoint than auth workflows
- ⚠️ n8n may return JResult envelope OR raw data - MUST normalize response
- ⚠️ Timeout should be longer for JQEL queries (30s) than auth queries (10s)

**Error Handling:**
- ⚠️ Invalid schema should return 400 Bad Request, not 404 Not Found
- ⚠️ Network errors to n8n should return 503 Service Unavailable, not 500
- ⚠️ MUST preserve original JResult error code from n8n (don't override)
- ⚠️ Unknown schemas default to application (route to n8n), don't fail

**Type Safety:**
- ⚠️ JQEL query types MUST match SPEC-jqel-syntax.md exactly
- ⚠️ WHERE clause operators use string keys (`"eq"`, `"ne"`) not symbols
- ⚠️ JResult data field is ALWAYS array, even for single record
- ⚠️ TypeScript strict mode enabled - all properties must be defined or optional

```typescript
// Based on SPEC-jqel-syntax.md

// SPEC-JQEL-STR-002: Complete query structure
export interface JQELQuery {
  schema: string;                          // SPEC-JQEL-STR-003: Required
  select?: string;                         // SPEC-JQEL-STR-004: select OR mutate required
  mutate?: string;
  action?: string;                         // SPEC-JQEL-STR-006: Required if mutate
  values?: Record<string, any>;
  where?: WhereClause;
  options?: QueryOptions;
  output?: string[];                       // SPEC-JQEL-PRJ-001: Projection by inclusion
  except?: string[];                       // SPEC-JQEL-PRJ-006: Projection by exclusion
}

// SPEC-JQEL-WHE-001: WHERE clause structure
export interface WhereClause {
  [field: string]: FieldCondition | LogicalOperator;
}

export interface FieldCondition {
  eq?: any;      // SPEC-JQEL-WHE-004: Equals
  ne?: any;      // Not equals
  gt?: any;      // Greater than
  gte?: any;     // Greater than or equal
  lt?: any;      // Less than
  lte?: any;     // Less than or equal
  in?: any[];    // SPEC-JQEL-WHE-006: In array
  like?: string; // SPEC-JQEL-WHE-009: Pattern matching
}

export interface LogicalOperator {
  or?: WhereClause[];  // SPEC-JQEL-WHE-015: OR operator
  not?: WhereClause;   // SPEC-JQEL-WHE-018: NOT operator
}

// SPEC-JQEL-OPT-003: Options structure
export interface QueryOptions {
  limit?: number;      // SPEC-JQEL-OPT-004: Max records
  offset?: number;     // SPEC-JQEL-OPT-008: Skip records
  orderBy?: OrderBy[]; // SPEC-JQEL-OPT-012: Sort order
}

export interface OrderBy {
  [field: string]: 'asc' | 'desc'; // SPEC-JQEL-OPT-014
}

// SPEC-JQEL-RES-002: JResult envelope
export interface JResult<T = any> {
  code: number;          // SPEC-JQEL-RES-003: HTTP status code
  message?: string;      // SPEC-JQEL-RES-006: Error description
  field?: string;        // SPEC-JQEL-RES-010: Field with error
  data?: T[];            // SPEC-JQEL-RES-013: Always array
  warnings?: JResult[];  // SPEC-JQEL-RES-017: Non-blocking alerts
}

// Schema types
export type SchemaType = 'backend' | 'platform' | 'system' | 'application';

// Routing context
export interface JqelContext {
  userId?: string;
  jwt?: string;
  ipAddress?: string;
  userAgent?: string;
}
```

#### Step 2: Create Backend Processor Service

Create: `src/prototype-2/backend/src/services/backendProcessor.service.ts`

**Details:** Implement processor for "backend" schema queries that access local JSON configuration files

**Pattern:** Follow singleton service pattern from `n8nProxy.service.ts`

```typescript
import fs from 'fs/promises';
import path from 'path';
import { JQELQuery, JResult } from '../types/jqel.types.js';

/**
 * BackendProcessorService
 *
 * Processes JQEL queries for "backend" schema.
 * Reads/writes portal, module, and instance configuration from local JSON files.
 *
 * SPEC References:
 * - SPEC-DA-SC-008: Backend schema processed locally
 * - SPEC-CH-DA-019: Backend schema MUST be processed by Backend
 */
export class BackendProcessorService {
  private readonly configDir: string;

  constructor() {
    // Configuration files in backend/config/
    this.configDir = path.join(process.cwd(), 'config');
  }

  /**
   * Process JQEL query for backend schema
   *
   * @param query - JQEL query object
   * @returns JResult with query results
   */
  async process(query: JQELQuery): Promise<JResult> {
    try {
      // Validate query
      if (!query.select && !query.mutate) {
        return {
          code: 400,
          message: 'Query must have either "select" or "mutate"',
        };
      }

      // Route to SELECT or MUTATE
      if (query.select) {
        return await this.processSelect(query);
      } else {
        return await this.processMutate(query);
      }
    } catch (error: any) {
      console.error('❌ Error in BackendProcessor:', error);
      return {
        code: 500,
        message: `Internal error: ${error.message}`,
      };
    }
  }

  /**
   * Process SELECT query
   *
   * Supports entities: portal, module, instance
   */
  private async processSelect(query: JQELQuery): Promise<JResult> {
    const entity = query.select!;
    const filePath = this.getConfigPath(entity);

    // Read configuration file
    let data: any[];
    try {
      const fileContent = await fs.readFile(filePath, 'utf-8');
      data = JSON.parse(fileContent);

      // Ensure data is array
      if (!Array.isArray(data)) {
        data = [data];
      }
    } catch (error: any) {
      // File not found or invalid JSON
      if (error.code === 'ENOENT') {
        // Return empty array for missing file (not an error)
        return { code: 200, data: [] };
      }

      return {
        code: 500,
        message: `Failed to read ${entity}: ${error.message}`,
      };
    }

    // Apply WHERE filter
    if (query.where) {
      data = this.applyWhere(data, query.where);
    }

    // Apply ORDER BY
    if (query.options?.orderBy) {
      data = this.applyOrderBy(data, query.options.orderBy);
    }

    // Apply OFFSET and LIMIT
    if (query.options?.offset) {
      data = data.slice(query.options.offset);
    }
    if (query.options?.limit) {
      data = data.slice(0, query.options.limit);
    }

    // Apply projection (OUTPUT or EXCEPT)
    if (query.output) {
      data = data.map(item => this.projectOutput(item, query.output!));
    } else if (query.except) {
      data = data.map(item => this.projectExcept(item, query.except!));
    }

    return { code: 200, data };
  }

  /**
   * Process MUTATE query
   *
   * Supports actions: insert, update, delete
   */
  private async processMutate(query: JQELQuery): Promise<JResult> {
    const entity = query.mutate!;
    const action = query.action;

    if (!action) {
      return {
        code: 400,
        message: 'Action is required for mutate',
        field: 'action',
      };
    }

    const filePath = this.getConfigPath(entity);

    // Read current data
    let data: any[];
    try {
      const fileContent = await fs.readFile(filePath, 'utf-8');
      data = JSON.parse(fileContent);

      if (!Array.isArray(data)) {
        data = [data];
      }
    } catch (error: any) {
      if (error.code === 'ENOENT') {
        // File doesn't exist - create empty array for insert
        data = [];
      } else {
        return {
          code: 500,
          message: `Failed to read ${entity}: ${error.message}`,
        };
      }
    }

    // Execute action
    let result: JResult;
    switch (action.toLowerCase()) {
      case 'insert':
        result = await this.insert(data, query, filePath);
        break;
      case 'update':
        result = await this.update(data, query, filePath);
        break;
      case 'delete':
        result = await this.delete(data, query, filePath);
        break;
      default:
        return {
          code: 400,
          message: `Unsupported action: ${action}`,
          field: 'action',
        };
    }

    return result;
  }

  /**
   * Insert new record
   */
  private async insert(
    data: any[],
    query: JQELQuery,
    filePath: string
  ): Promise<JResult> {
    if (!query.values) {
      return {
        code: 400,
        message: 'Values are required for insert',
        field: 'values',
      };
    }

    // Add new record
    data.push(query.values);

    // Write back to file
    await this.writeConfig(filePath, data);

    return { code: 201, data: [query.values] };
  }

  /**
   * Update existing records
   */
  private async update(
    data: any[],
    query: JQELQuery,
    filePath: string
  ): Promise<JResult> {
    if (!query.where) {
      return {
        code: 400,
        message: 'WHERE clause is required for update',
        field: 'where',
      };
    }

    if (!query.values) {
      return {
        code: 400,
        message: 'Values are required for update',
        field: 'values',
      };
    }

    // Find matching records
    const matches = this.applyWhere(data, query.where);

    if (matches.length === 0) {
      return { code: 200, data: [] };
    }

    // Update matching records
    data = data.map(item => {
      const isMatch = matches.some(m => JSON.stringify(m) === JSON.stringify(item));
      if (isMatch) {
        return { ...item, ...query.values };
      }
      return item;
    });

    // Write back to file
    await this.writeConfig(filePath, data);

    // Return updated records
    const updated = this.applyWhere(data, query.where);
    return { code: 200, data: updated };
  }

  /**
   * Delete records
   */
  private async delete(
    data: any[],
    query: JQELQuery,
    filePath: string
  ): Promise<JResult> {
    if (!query.where) {
      return {
        code: 400,
        message: 'WHERE clause is required for delete',
        field: 'where',
      };
    }

    // Find matching records
    const matches = this.applyWhere(data, query.where);
    const beforeCount = data.length;

    // Remove matching records
    data = data.filter(item => {
      return !matches.some(m => JSON.stringify(m) === JSON.stringify(item));
    });

    // Write back to file
    await this.writeConfig(filePath, data);

    const deletedCount = beforeCount - data.length;
    return { code: 200, message: `${deletedCount} records deleted` };
  }

  /**
   * Apply WHERE clause filter
   */
  private applyWhere(data: any[], where: any): any[] {
    return data.filter(item => this.matchesWhere(item, where));
  }

  /**
   * Check if item matches WHERE clause
   */
  private matchesWhere(item: any, where: any): boolean {
    // Handle logical operators
    if (where.or) {
      return where.or.some((condition: any) => this.matchesWhere(item, condition));
    }

    if (where.not) {
      return !this.matchesWhere(item, where.not);
    }

    // Handle field conditions (AND is implicit)
    return Object.entries(where).every(([field, condition]: [string, any]) => {
      const value = item[field];

      // Handle operators
      if (condition.eq !== undefined) return value === condition.eq;
      if (condition.ne !== undefined) return value !== condition.ne;
      if (condition.gt !== undefined) return value > condition.gt;
      if (condition.gte !== undefined) return value >= condition.gte;
      if (condition.lt !== undefined) return value < condition.lt;
      if (condition.lte !== undefined) return value <= condition.lte;
      if (condition.in !== undefined) return condition.in.includes(value);
      if (condition.like !== undefined) {
        const pattern = condition.like.replace(/%/g, '.*').replace(/_/g, '.');
        return new RegExp(`^${pattern}$`, 'i').test(value);
      }

      return true;
    });
  }

  /**
   * Apply ORDER BY
   */
  private applyOrderBy(data: any[], orderBy: any[]): any[] {
    return data.sort((a, b) => {
      for (const orderRule of orderBy) {
        const [field, direction] = Object.entries(orderRule)[0] as [string, 'asc' | 'desc'];
        const aVal = a[field];
        const bVal = b[field];

        if (aVal < bVal) return direction === 'asc' ? -1 : 1;
        if (aVal > bVal) return direction === 'asc' ? 1 : -1;
      }
      return 0;
    });
  }

  /**
   * Project fields (include only specified)
   */
  private projectOutput(item: any, fields: string[]): any {
    const result: any = {};
    for (const field of fields) {
      if (item.hasOwnProperty(field)) {
        result[field] = item[field];
      }
    }
    return result;
  }

  /**
   * Project fields (exclude specified)
   */
  private projectExcept(item: any, fields: string[]): any {
    const result = { ...item };
    for (const field of fields) {
      delete result[field];
    }
    return result;
  }

  /**
   * Get configuration file path for entity
   */
  private getConfigPath(entity: string): string {
    // Map entity names to file names
    const fileNames: Record<string, string> = {
      portal: 'portals.json',
      module: 'modules.json',
      instance: 'instances.json',
    };

    const fileName = fileNames[entity];
    if (!fileName) {
      throw new Error(`Unknown backend entity: ${entity}`);
    }

    return path.join(this.configDir, fileName);
  }

  /**
   * Write configuration to file
   */
  private async writeConfig(filePath: string, data: any[]): Promise<void> {
    await fs.writeFile(filePath, JSON.stringify(data, null, 2), 'utf-8');
  }
}

export const backendProcessor = new BackendProcessorService();
```

#### Step 4: Create JQEL Router Service

Create: `src/prototype-2/backend/src/services/jqelRouter.service.ts`

**Details:** Implement schema classification and routing logic

**Pattern:** Singleton service with classification logic

```typescript
import { JQELQuery, JResult, SchemaType, JqelContext } from '../types/jqel.types.js';
import { backendProcessor } from './backendProcessor.service.js';
import { n8nProxyService } from './n8nProxy.service.js';
import { config } from '../config/env.js';

/**
 * JqelRouterService
 *
 * Routes JQEL queries to appropriate processor based on schema.
 *
 * Schema routing rules (SPEC-DA-SC-001:007):
 * - "backend" → BackendProcessor (local file processing)
 * - "platform" → N8nProxy (backbone processing)
 * - "system" → Configurable (env var)
 * - [other] → N8nProxy (application schemas)
 *
 * SPEC References:
 * - SPEC-DA-SC-001:007: Schema-based routing rules
 * - SPEC-CH-RO-001:021: Channel routing by schema
 */
export class JqelRouterService {
  private readonly reservedSchemas = ['backend', 'platform', 'system'];

  /**
   * Route JQEL query to appropriate processor
   *
   * @param query - JQEL query object
   * @param context - Request context (user, IP, etc.)
   * @returns JResult from processor
   */
  async route(query: JQELQuery, context?: JqelContext): Promise<JResult> {
    try {
      // Validate schema field
      if (!query.schema || typeof query.schema !== 'string') {
        return {
          code: 400,
          message: 'Schema is required and must be a string',
          field: 'schema',
        };
      }

      // Classify schema type
      const schemaType = this.classifySchema(query.schema);

      // Log routing decision
      console.log(`ℹ️  Routing JQEL query:`, {
        schema: query.schema,
        type: schemaType,
        operation: query.select ? 'select' : 'mutate',
        entity: query.select || query.mutate,
      });

      // Route to appropriate processor
      switch (schemaType) {
        case 'backend':
          return await backendProcessor.process(query);

        case 'platform':
        case 'application':
          return await n8nProxyService.query(query);

        case 'system':
          // Check environment variable for system schema routing
          const systemTarget = config.systemSchemaTarget || 'n8n';

          if (systemTarget === 'backend') {
            return await backendProcessor.process(query);
          } else {
            return await n8nProxyService.query(query);
          }

        default:
          // Should never reach here
          return {
            code: 500,
            message: `Unknown schema type: ${schemaType}`,
          };
      }
    } catch (error: any) {
      console.error('❌ Error in JqelRouter:', error);

      // Map service errors to HTTP errors
      if (error.message?.includes('n8n unreachable')) {
        return {
          code: 503,
          message: 'Query service is unavailable',
        };
      }

      if (error.message?.includes('timeout')) {
        return {
          code: 504,
          message: 'Query timed out',
        };
      }

      return {
        code: 500,
        message: `Query processing failed: ${error.message}`,
      };
    }
  }

  /**
   * Classify schema into routing category
   *
   * SPEC-JQEL-SCH-004:006: Schema classification rules
   *
   * @param schema - Schema name from query
   * @returns Schema type (backend, platform, system, application)
   */
  private classifySchema(schema: string): SchemaType {
    const normalizedSchema = schema.toLowerCase();

    // SPEC-DA-SC-008: backend schema processed locally
    if (normalizedSchema === 'backend') {
      return 'backend';
    }

    // SPEC-DA-SC-007: platform schema proxied to n8n
    if (normalizedSchema === 'platform') {
      return 'platform';
    }

    // SPEC-DA-SC-009: system schema routing is configurable
    if (normalizedSchema === 'system') {
      return 'system';
    }

    // SPEC-DA-SC-006: Non-reserved schemas are application schemas
    // Route to n8n by default
    return 'application';
  }

  /**
   * Check if schema is reserved by platform
   */
  isReservedSchema(schema: string): boolean {
    return this.reservedSchemas.includes(schema.toLowerCase());
  }
}

export const jqelRouter = new JqelRouterService();
```

#### Step 5: Create JQEL Route Handler

**Pattern:** Follow auth.routes.ts structure

```typescript
import { Router, Request, Response, NextFunction } from 'express';
import { jqelRouter } from '../services/jqelRouter.service.js';
import { jwtService } from '../services/jwt.service.js';
import type { JQELQuery, JqelContext } from '../types/jqel.types.js';

const router = Router();

/**
 * POST /api/jqel
 *
 * Process JQEL query.
 * Routes to appropriate processor based on schema.
 *
 * SPEC References:
 * - SPEC-DA-EP-001:009: JQEL endpoint accepts POST with JSON
 * - SPEC-DA-SC-001:007: Schema-based routing
 * - SPEC-JQEL-RES-001:009: Return JResult envelope
 */
router.post(
  '/',
  async (req: Request, res: Response, next: NextFunction): Promise<void> => {
    try {
      // Extract JQEL query from body
      const query: JQELQuery = req.body;

      // Basic validation - ensure it's an object
      if (!query || typeof query !== 'object') {
        res.status(400).json({
          code: 400,
          message: 'Request body must be a valid JQEL query object',
        });
        return;
      }

      // Validate required fields
      if (!query.schema) {
        res.status(400).json({
          code: 400,
          message: 'Schema is required',
          field: 'schema',
        });
        return;
      }

      if (!query.select && !query.mutate) {
        res.status(400).json({
          code: 400,
          message: 'Query must have either "select" or "mutate"',
        });
        return;
      }

      // SPEC-JQEL-STR-005: select and mutate are mutually exclusive
      if (query.select && query.mutate) {
        res.status(400).json({
          code: 400,
          message: 'Query cannot have both "select" and "mutate"',
        });
        return;
      }

      // SPEC-JQEL-STR-006: mutate requires action
      if (query.mutate && !query.action) {
        res.status(400).json({
          code: 400,
          message: 'Action is required for mutate',
          field: 'action',
        });
        return;
      }

      // SPEC-JQEL-PRJ-013:015: output and except are mutually exclusive
      if (query.output && query.except) {
        res.status(400).json({
          code: 400,
          message: 'Query cannot have both "output" and "except"',
        });
        return;
      }

      // Extract JWT from Authorization header (optional)
      // Some queries may not require authentication
      let context: JqelContext = {
        ipAddress: req.ip,
        userAgent: req.get('user-agent'),
      };

      const authHeader = req.headers.authorization;
      if (authHeader && authHeader.startsWith('Bearer ')) {
        const accessToken = authHeader.substring(7);

        try {
          const payload = jwtService.verifyAccessToken(accessToken);
          context.userId = payload.sub;
          context.jwt = accessToken;
        } catch (error) {
          // Invalid or expired JWT
          // For now, continue without authentication
          // Authorization check will be done by processor if needed
          console.warn('⚠️  Invalid JWT in JQEL request:', error);
        }
      }

      // Route query to appropriate processor
      const result = await jqelRouter.route(query, context);

      // SPEC-JQEL-RES-003:004: Use code field for HTTP status
      const statusCode = result.code || 200;

      // Return JResult envelope
      res.status(statusCode).json(result);
    } catch (error) {
      console.error('❌ Error in /api/jqel:', error);
      next(error);
    }
  }
);

export default router;
```

### Error Handling Strategy

**Error Types:**

1. **Validation Errors (400 Bad Request)**
   - Missing required fields (schema, select/mutate, action)
   - Invalid field types (schema not string, limit not number)
   - Mutually exclusive fields (select + mutate, output + except)
   - Response: JResult with code 400, descriptive message, field name

2. **Schema Errors (400 Bad Request)**
   - Unknown backend entity (portal, module, instance only)
   - Invalid schema name format
   - Response: JResult with code 400, message explains valid entities

3. **File System Errors (500 Internal Server Error)**
   - Permission denied reading config file
   - Invalid JSON in config file
   - Write failure (disk full, read-only)
   - Response: JResult with code 500, generic message (don't expose internals)

4. **Network Errors (503 Service Unavailable)**
   - n8n unreachable (connection refused, DNS failure)
   - Response: JResult with code 503, "Query service is unavailable"

5. **Timeout Errors (504 Gateway Timeout)**
   - n8n query exceeds 30s timeout
   - Response: JResult with code 504, "Query timed out"

6. **n8n Errors (Variable)**
   - Preserve n8n's JResult code (400, 401, 403, 404, 422, 500)
   - Pass through n8n's message and field
   - Response: Original JResult from n8n

**Error Display Pattern:**

```typescript
// Route handler
try {
  const result = await jqelRouter.route(query);
  res.status(result.code).json(result);
} catch (error) {
  console.error('❌ Error:', error);
  next(error); // Pass to Express error handler
}

// Service layer
if (validationFails) {
  return {
    code: 400,
    message: 'Descriptive error message',
    field: 'fieldName', // Optional
  };
}

// Async operations
try {
  const result = await operation();
  return { code: 200, data: result };
} catch (error: any) {
  if (error.code === 'ENOENT') {
    return { code: 404, message: 'Resource not found' };
  }
  throw error; // Re-throw unexpected errors
}
```

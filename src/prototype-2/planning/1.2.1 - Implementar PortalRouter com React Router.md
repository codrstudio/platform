# Task Plan: 1.2.1 - Implementar PortalRouter com React Router

## Context and Objective

This task implements the foundational routing system for the platform, establishing how portals and their modules are routed using React Router. The PortalRouter is responsible for:

- Loading portal configurations from backend (via JQEL)
- Identifying which modules are active in each portal
- Dynamically loading modules using lazy loading (React.lazy)
- Injecting module routes into React Router with proper prefixes
- Managing route priorities (main portal has absolute priority)
- Providing loading states during portal/module loading

This is a critical infrastructure component that enables all subsequent module development. Without the PortalRouter, modules cannot be loaded or routed properly. The implementation must follow the specifications for routing (SPEC-routing.md), module loading (SPEC-module-loading.md), and core concepts (SPEC-concepts.md).

### Gotchas and Pitfalls

**React Router v7 Changes:**
- React Router v7 introduced data routers (`createBrowserRouter`) as preferred approach
- However, we'll use `BrowserRouter` + `Routes` for dynamic route injection (simpler for our use case)
- Data routers are static by design, not ideal for runtime module loading
- Our approach is valid and recommended for dynamic routing scenarios

**Dynamic Import Path Resolution:**
- Vite requires dynamic imports to have static path structure
- Wrong: `import(dynamicVariable)` (won't work)
- Right: `import(\`/modules/\${moduleId}/index.ts\`)` (works with limitations)
- Even better: Use static import map with dynamic keys (our approach)

**Module Loading Race Conditions:**
- Loading multiple modules in parallel can cause race conditions
- Use `Promise.all()` for parallel loading (faster)
- Ensure module registry is synchronized (use React state, not external variables)

**Portal Route Priority:**
- Main portal ("/") must be defined BEFORE "/:portalId/*"
- React Router matches in definition order
- Without correct order, "/:portalId/*" will catch "/" incorrectly

**React Suspense Boundaries:**
- Each lazy-loaded module needs Suspense boundary
- Portal-level Suspense catches all module loading
- Show meaningful loading indicators (don't just show blank screen)

**TypeScript Dynamic Import Types:**
- Dynamic imports return `Promise<typeof module>`
- Module exports need proper typing for IDE support
- Use consistent module export structure

### Data Flow

**Portal Loading Flow:**
```
1. User navigates to URL (e.g., "/setup")
2. React Router matches route
3. PortalLoader extracts portalId from URL or uses "main"
4. usePortalConfig hook fetches portal configuration (mock for now)
5. useModuleLoader loads active modules in parallel
6. Each module loaded via dynamic import + React.lazy
7. PortalRouter receives loaded modules
8. Routes are injected into React Router declaratively
9. Portal renders with active modules
```

**Route Registration Flow:**
```
Module Definition (setup/routes.ts):
  { path: "/", component: SetupHome }
  { path: "/portals", component: PortalList }

Portal: "setup" (path: /setup)

PortalRouter prefixes routes:
  /setup/ → SetupHome
  /setup/portals → PortalList

React Router final routes:
  /setup → SetupHome
  /setup/portals → PortalList
```

**Module Loading Flow:**
```
ModuleRegistry (singleton)
  ↓
ModuleLoader.loadModule(moduleId)
  ↓
Dynamic import: React.lazy(() => import(`/modules/${moduleId}/index.ts`))
  ↓
Module exports: { routes, components, onActivate }
  ↓
Register in ModuleRegistry
  ↓
Return to PortalRouter
  ↓
Inject routes into React Router
```

```typescript
// Singleton pattern
class ModuleRegistry {
  private modules: Map<string, ModuleExports>;
  private loading: Map<string, Promise<ModuleExports>>;

  constructor() {
    this.modules = new Map();
    this.loading = new Map();
  }

  has(moduleId: string): boolean {
    return this.modules.has(moduleId);
  }

  get(moduleId: string): ModuleExports | undefined {
    return this.modules.get(moduleId);
  }

  register(moduleId: string, exports: ModuleExports): void {
    this.modules.set(moduleId, exports);
  }

  isLoading(moduleId: string): boolean {
    return this.loading.has(moduleId);
  }

  setLoading(moduleId: string, promise: Promise<ModuleExports>): void {
    this.loading.set(moduleId, promise);
  }

  clearLoading(moduleId: string): void {
    this.loading.delete(moduleId);
  }
}

// Export singleton instance
export const moduleRegistry = new ModuleRegistry();
```

**Pattern:** Singleton with Map for O(1) lookups, prevent duplicate loading

**Details:**
```typescript
import React from 'react';
import { moduleRegistry } from './ModuleRegistry';
import type { ModuleExports } from '../../types/module';

export class ModuleLoader {
  /**
   * Loads a module dynamically using React.lazy
   * Returns module exports or throws error
   */
  static async loadModule(moduleId: string): Promise<ModuleExports> {
    // Check if already loaded
    if (moduleRegistry.has(moduleId)) {
      return moduleRegistry.get(moduleId)!;
    }

    // Check if currently loading
    if (moduleRegistry.isLoading(moduleId)) {
      return moduleRegistry.loading.get(moduleId)!;
    }

    // Start loading
    const loadingPromise = this.performLoad(moduleId);
    moduleRegistry.setLoading(moduleId, loadingPromise);

    try {
      const exports = await loadingPromise;
      moduleRegistry.register(moduleId, exports);
      moduleRegistry.clearLoading(moduleId);
      return exports;
    } catch (error) {
      moduleRegistry.clearLoading(moduleId);
      throw error;
    }
  }

  private static async performLoad(moduleId: string): Promise<ModuleExports> {
    try {
      // Dynamic import with static path structure (Vite requirement)
      const module = await import(`../../modules/${moduleId}/index.ts`);

      // Validate module exports
      if (!module.default) {
        throw new Error(`Module ${moduleId} does not have default export`);
      }

      return module.default as ModuleExports;
    } catch (error) {
      console.error(`Failed to load module ${moduleId}:`, error);
      throw new Error(`Module ${moduleId} failed to load`);
    }
  }

  /**
   * Loads multiple modules in parallel
   */
  static async loadModules(moduleIds: string[]): Promise<ModuleExports[]> {
    return Promise.all(moduleIds.map(id => this.loadModule(id)));
  }
}
```

**Pattern:** Static utility class, Promise-based, handles caching and loading state

```typescript
import { useState, useEffect } from 'react';
import { ModuleLoader } from '../core/modules/ModuleLoader';
import type { ModuleExports } from '../types/module';

interface UseModuleLoaderResult {
  modules: ModuleExports[];
  loading: boolean;
  error: Error | null;
}

export function useModuleLoader(moduleIds: string[]): UseModuleLoaderResult {
  const [modules, setModules] = useState<ModuleExports[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  useEffect(() => {
    if (moduleIds.length === 0) {
      setModules([]);
      setLoading(false);
      return;
    }

    const loadModules = async () => {
      setLoading(true);
      setError(null);

      try {
        const loaded = await ModuleLoader.loadModules(moduleIds);
        setModules(loaded);
      } catch (err) {
        setError(err instanceof Error ? err : new Error('Failed to load modules'));
        setModules([]);
      } finally {
        setLoading(false);
      }
    };

    loadModules();
  }, [moduleIds.join(',')]); // Dependency on array content, not reference

  return { modules, loading, error };
}
```

**Pattern:** Standard hook pattern, handles loading state, arrays as dependencies

```typescript
          </div>
        )}
      </div>
    );
  }

  // Error state
  if (portalError) {
    return (
      <div style={{ padding: '2rem', textAlign: 'center', color: 'red' }}>
        <div>Error loading portal: {portalError.message}</div>
      </div>
    );
  }

  if (modulesError) {
    return (
      <div style={{ padding: '2rem', textAlign: 'center', color: 'red' }}>
        <div>Error loading modules: {modulesError.message}</div>
      </div>
    );

    return (
      <div style={{ padding: '2rem', textAlign: 'center' }}>
        <div>Portal not found: {portalId}</div>
      </div>

  return (
```

**Details:**
```typescript
import React, { useMemo } from 'react';
import { Routes, Route } from 'react-router-dom';
import type { Portal } from '../../types/portal';
import type { ModuleExports } from '../../types/module';
import type { PrefixedRoute } from '../../types/routing';

interface PortalRouterProps {
  portal: Portal;
  modules: ModuleExports[];
}

export default function PortalRouter({ portal, modules }: PortalRouterProps) {
  // Extract and prefix routes from all modules
  const routes = useMemo(() => {
    const allRoutes: PrefixedRoute[] = [];

    modules.forEach(module => {
      if (!module.routes) return;

      module.routes.forEach(route => {
        // Prefix route with portal path
        // Main portal (/) should not have prefix
        // Other portals (/setup) should have prefix
        const prefixedPath = portal.portalId === 'main'
          ? route.path
          : route.path === '/'
            ? '' // Root of portal (e.g., /setup)
            : route.path; // Sub-route (e.g., /portals becomes /setup/portals)

        allRoutes.push({
          ...route,
          originalPath: route.path,
          prefixedPath,
        });
      });
    });

    return allRoutes;
  }, [portal, modules]);

  // Execute onActivate for all modules (on mount)
  React.useEffect(() => {
    modules.forEach(module => {
      if (module.onActivate) {
        module.onActivate(portal);
      }
    });

    // Cleanup: execute onDeactivate on unmount
    return () => {
      modules.forEach(module => {
        if (module.onDeactivate) {
          module.onDeactivate(portal);
        }
      });
    };
  }, [modules, portal]);

  // No routes - show empty portal
  if (routes.length === 0) {
    return (
      <div style={{ padding: '2rem' }}>
        <h2>{portal.name}</h2>
        <p>No modules active in this portal.</p>
        <p style={{ fontSize: '0.875rem', color: '#666' }}>
          Portal ID: {portal.portalId}
        </p>
      </div>
    );
  }

  // Render routes
  return (
    <Routes>
      {routes.map((route, index) => (
        <Route
          key={`${route.prefixedPath}-${index}`}
          path={route.prefixedPath}
          element={<route.component />}
        />
      ))}

      {/* 404 fallback for unmatched routes within portal */}
      <Route
        path="*"
        element={
          <div style={{ padding: '2rem' }}>
            <h2>Page Not Found</h2>
            <p>The requested page does not exist in {portal.name}.</p>
          </div>
        }
      />
    </Routes>
  );
}
```

**Pattern:** Declarative route injection, useMemo for performance, lifecycle hooks

```typescript
      </Routes>
    </BrowserRouter>
  );
}
```

**Pattern:** SPEC-R-CA-009 structure, main portal priority, catch-all for other portals

### Error Handling Strategy

**Module Loading Errors:**
- If module fails to load, catch in ModuleLoader
- Return error from useModuleLoader hook
- Display error message in PortalLoader
- Portal continues to work with successfully loaded modules (graceful degradation)

**Portal Configuration Errors:**
- If portal not found, display "Portal not found" message
- User can navigate back or to a different portal
- No application crash

**Route Errors:**
- React Router handles unmatched routes with 404 fallback
- Each portal has its own 404 page
- Global 404 for unmatched portals (future enhancement)

**Loading State Management:**
- Use separate loading flags for portal and modules
- Show progressive loading states (portal, then modules)
- Never show blank screen - always show loading indicator

**TypeScript Safety:**
- All types properly defined
- No `any` types unless absolutely necessary
- Strict null checks enabled

# Task Plan: 1.2.9 - Implementar redirecionamento para login

## Context and Objective

This task implements the login redirect functionality for protected routes in the Platform routing system. When an unauthenticated user attempts to access a protected route, they must be automatically redirected to the login page with a return URL parameter, allowing seamless return to their intended destination after successful authentication.

This is a critical security and user experience feature that integrates with the ProtectedRoute component (task 1.2.8) and prepares the foundation for the authentication system (System 1.3). The implementation ensures that protected routes are inaccessible without authentication while maintaining a smooth user flow.

**Business Value:**
- Prevents unauthorized access to protected resources
- Improves user experience by remembering intended destination
- Establishes security boundary between public and protected routes
- Enables gradual authentication without losing user context

**Integration Points:**
- Works with ProtectedRoute component to detect authentication state
- Coordinates with AuthContext/AuthProvider for authentication checks
- Prepares integration points for login module implementation
- Maintains React Router navigation state for seamless flow

### Gotchas and Pitfalls

**React Router v6 Changes:**
- v6 removed `<Redirect>` component, use `<Navigate>` instead
- Use `replace` prop to avoid infinite back button loops
- Location state is preferred over query params for security

**Open Redirect Vulnerability:**
- ALWAYS validate return URLs to prevent malicious redirects
- Only allow relative paths (start with `/`)
- Reject absolute URLs or protocol-relative URLs (`//evil.com`)
- Whitelist allowed redirect paths if needed

**Authentication Loading State:**
- Must handle loading state to prevent flash of redirect
- Show loading spinner while authentication state is being determined
- Only redirect after confirming user is NOT authenticated (not just undefined)

**Portal-based Routing:**
- Main portal uses `/` base
- Other portals use `/:portalId/*` base
- Login path may be portal-specific: `/login` or `/:portalId/login`
- Return URL must preserve portal context

**Infinite Redirect Loop:**
- Use `replace` prop on `<Navigate>` to replace history entry
- Prevents user from clicking back and triggering redirect again
- Login page itself must NOT be protected

**Query Parameter Encoding:**
- URL must be properly encoded with `encodeURIComponent`
- Decode with `decodeURIComponent` on the other end
- Handle special characters correctly

**Navigation Timing:**
- Redirect should happen synchronously in render
- Do NOT use `useNavigate` hook for auth redirects (causes double render)
- Use declarative `<Navigate>` component instead

│  e.g., /dashboard                               │

                 ▼

                 │

                      └─> Redirect to login

                          │    to="/login"          │

                      │  Login Page                 │
                      │  - Receives location.state  │
                      │  - Extracts 'from' path     │
                      │  - After auth success:      │
                      │    navigate(from || '/')    │
                      └─────────────────────────────┘
```

### Data Flow

**1. Protected Route Access Attempt:**
```
User navigates to /dashboard
  → React Router matches route
  → <ProtectedRoute> wrapper renders
  → Reads auth state from AuthContext
```

**2. Authentication Check:**
```
AuthContext provides:
  - isAuthenticated: boolean
  - isLoading: boolean
  - user: User | null

ProtectedRoute evaluates:
  if (isLoading) → show loading
  if (!isAuthenticated) → redirect
  else → render children
```

**3. Redirect Execution:**
```
<Navigate
  to="/login"
  state={{ from: location }}
  replace
/>
  → React Router navigates to /login
  → Passes current location in state
  → Replaces history entry (no back button loop)
```

**4. Post-Login Return:**
```
Login component:
  const location = useLocation();
  const from = location.state?.from?.pathname || '/';

After successful login:
  navigate(from, { replace: true });
  → User returns to originally requested page
```

**Example Implementation:**

```typescript
// frontend/src/core/routing/ProtectedRoute.tsx
import { PropsWithChildren } from 'react';
import { Navigate, useLocation } from 'react-router-dom';
import type { Location } from 'react-router-dom';
import { useAuth } from '@/providers/AuthProvider';

/**
 * Location state passed during login redirect
 */
interface LocationState {
  from?: Location;
}

/**
 * Validates that a return URL is safe to redirect to.
 * Prevents open redirect vulnerabilities.
 */
function isValidReturnUrl(url: string): boolean {
  // Only allow relative URLs starting with /
  if (!url.startsWith('/')) return false;

  // Reject protocol-relative URLs
  if (url.startsWith('//')) return false;

  // Reject data/javascript URLs
  if (url.match(/^(data|javascript):/i)) return false;

  return true;
}

/**
 * ProtectedRoute component that requires authentication.
 * Redirects unauthenticated users to login with return URL.
 *
 * Usage:
 * ```tsx
 * <Route path="/dashboard" element={
 *   <ProtectedRoute>
 *     <Dashboard />
 *   </ProtectedRoute>
 * } />
 * ```
 *
 * After login, redirect using:
 * ```tsx
 * const location = useLocation();
 * const from = (location.state as LocationState)?.from?.pathname || '/';
 * if (isValidReturnUrl(from)) {
 *   navigate(from, { replace: true });
 * }
 * ```
 */
export function ProtectedRoute({ children }: PropsWithChildren) {
  const { isAuthenticated, isLoading } = useAuth();
  const location = useLocation();

  // Show loading state while checking authentication
  if (isLoading) {
    return (
      <div className="flex items-center justify-center min-h-screen">
        <div
          className="animate-spin rounded-full h-12 w-12 border-b-2 border-gray-900 dark:border-gray-100"
          role="status"
          aria-label="Loading"
        />
      </div>
    );
  }

  // Redirect to login if not authenticated
  if (!isAuthenticated) {
    // Prevent redirect loop if already on login page
    if (location.pathname === '/login') {
      return <>{children}</>;
    }

    // Redirect to login with return URL
    return (
      <Navigate
        to="/login"
        state={{ from: location } satisfies LocationState}
        replace
      />
    );
  }

  // User is authenticated, render protected content
  return <>{children}</>;
}
```

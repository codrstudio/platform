# Task Plan: 1.3.8 - Implementar detecção de reuso de tokens

## Context and Objective

### What will be implemented
This task implements refresh token reuse detection in the Backend layer to protect against token theft attacks. When a previously-used (consumed) refresh token is presented again, the system will detect this as a security breach and revoke the entire token family to prevent session hijacking.

### Why it's needed
Token reuse detection is a critical security mechanism that protects users when their refresh tokens are stolen. Without it, an attacker who obtains a refresh token could use it to maintain persistent access even after the legitimate user has refreshed their session.

### How it integrates
The Backend acts as a proxy between Frontend and Backbone (n8n). This task adds a validation layer that:
1. Checks if a refresh token has already been consumed (via Redis cache)
2. If reused, triggers family-wide revocation before forwarding to Backbone
3. If valid, forwards the request to Backbone normally

### Business value
- Prevents session hijacking by detecting and responding to token theft
- Provides automatic incident response (family revocation) without user intervention
- Meets security best practices for OAuth 2.0 refresh token rotation

### User impact
Users are protected transparently - they won't notice the security mechanism unless their token is stolen, in which case all sessions will be invalidated and they'll need to re-authenticate (protecting them from the attacker).

### Gotchas and Pitfalls

**Redis Connection:**
- Always implement retry strategy - network failures are common
- Handle Redis unavailability gracefully (fail open vs fail closed decision)
- Close Redis connection on server shutdown to prevent hanging connections
- Use connection pooling implicitly provided by ioredis

**Token Hashing:**
- Never store raw refresh tokens in Redis
- Use SHA-256 for token hashing (consistent with n8n workflows)
- Hash tokens before lookup to prevent timing attacks
- Refresh token from request body must be hashed before Redis query

**Race Conditions:**
- Token consumption check and update must be atomic
- Use Redis transactions (MULTI/EXEC) or Lua scripts for atomicity
- Watch out for concurrent refresh requests from same token

**Error Handling:**
- Distinguish between "token reused" (security incident) vs "Redis unavailable" (infrastructure issue)
- Token reused: Return 401, revoke family
- Redis unavailable: Log error, decide fail-open (allow) or fail-closed (deny)

**Performance:**
- Cache lookups are fast (<1ms) but add latency to refresh endpoint
- Set reasonable TTL on token family records (match refresh token expiration)
- Consider Redis key expiration to auto-cleanup old records

#### 4. Implement TokenFamilyService
- Create: `src/services/tokenFamily.service.ts`
- Details: Token family operations using RedisService
- Pattern: Static methods for business logic

```typescript
import crypto from 'crypto';
import { RedisService } from './redis.service.js';
import { TokenFamilyRecord, TokenReuseError } from '../types/token.types.js';
import { config } from '../config/env.js';

export class TokenFamilyService {
  private static redis = RedisService.getInstance();

  /**
   * Hash refresh token using SHA-256 (matches n8n implementation)
   */
  public static hashToken(token: string): string {
    return crypto.createHash('sha256').update(token).digest('hex');
  }

  /**
   * Get token family record from Redis
   */
  public static async getTokenRecord(
    tokenHash: string
  ): Promise<TokenFamilyRecord | null> {
    const key = `token:family:${tokenHash}`;
    const data = await this.redis.get(key);

    if (!data) {
      return null;
    }

    return JSON.parse(data) as TokenFamilyRecord;
  }

  /**
   * Check if token has been consumed (reused)
   */
  public static async isTokenReused(tokenHash: string): Promise<boolean> {
    const record = await this.getTokenRecord(tokenHash);

    if (!record) {
      // Token not found in cache - might be from n8n, let it pass
      return false;
    }

    // Token is reused if consumed_at is not null
    return record.consumed_at !== null;
  }

  /**
   * Mark token as consumed (atomic operation)
   */
  public static async markTokenConsumed(tokenHash: string): Promise<void> {
    const record = await this.getTokenRecord(tokenHash);

    if (!record) {
      // Token not in cache yet - will be added by n8n after rotation
      return;
    }

    const updatedRecord: TokenFamilyRecord = {
      ...record,
      consumed_at: new Date().toISOString(),
    };

    // Calculate TTL based on expires_at
    const expiresAt = new Date(record.expires_at);
    const now = new Date();
    const ttlSeconds = Math.max(0, Math.floor((expiresAt.getTime() - now.getTime()) / 1000));

    const key = `token:family:${tokenHash}`;
    await this.redis.set(key, JSON.stringify(updatedRecord), ttlSeconds);
  }

  /**
   * Revoke entire token family
   */
  public static async revokeTokenFamily(familyId: string): Promise<void> {
    // Find all tokens in this family
    const pattern = 'token:family:*';
    const keys = await this.redis.keys(pattern);

    const multi = this.redis.multi();

    for (const key of keys) {
      const data = await this.redis.get(key);
      if (data) {
        const record = JSON.parse(data) as TokenFamilyRecord;

        if (record.family_id === familyId) {
          // Mark token as revoked
          const revokedRecord: TokenFamilyRecord = {
            ...record,
            revoked: true,
          };

          // Calculate TTL
          const expiresAt = new Date(record.expires_at);
          const now = new Date();
          const ttlSeconds = Math.max(0, Math.floor((expiresAt.getTime() - now.getTime()) / 1000));

          multi.set(key, JSON.stringify(revokedRecord), 'EX', ttlSeconds);
        }
      }
    }

    // Also set family-wide revocation marker
    const familyKey = `token:family:revoked:${familyId}`;
    // Use max TTL from config (7 days)
    const ttl = this.parseDuration(config.jwtRefreshTokenExpiresIn);
    multi.set(familyKey, 'true', 'EX', ttl);

    await multi.exec();
  }

  /**
   * Parse duration string (e.g., "7d", "15m") to seconds
   */
  private static parseDuration(duration: string): number {
    const match = duration.match(/^(\d+)([smhd])$/);
    if (!match) {
      return 604800; // Default 7 days
    }

    const value = parseInt(match[1], 10);
    const unit = match[2];

    const multipliers: Record<string, number> = {
      s: 1,
      m: 60,
      h: 3600,
      d: 86400,
    };

    return value * (multipliers[unit] || 1);
  }
}
```

#### 5. Implement Token Reuse Middleware
- Create: `src/middleware/tokenReuse.middleware.ts`
- Details: Express middleware to detect and handle token reuse
- Pattern: See existing middleware in `src/middleware/*.ts`

```typescript
import { Request, Response, NextFunction } from 'express';
import { TokenFamilyService } from '../services/tokenFamily.service.js';

/**
 * Middleware to detect refresh token reuse
 *
 * SPEC-AU-RF-008: Backend DEVE detectar reuso de token
 * SPEC-AU-RF-009: Reuso detectado DEVE revogar família inteira
 * SPEC-AU-RF-019: Reuso detectado DEVE retornar HTTP 401
 */
export const tokenReuseDetection = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  try {
    // Extract refresh token from body or cookie
    const refreshToken = req.body.refresh_token || req.cookies?.refresh_token;

    if (!refreshToken) {
      // No token provided - let auth route handle validation
      return next();
    }

    // Hash the token
    const tokenHash = TokenFamilyService.hashToken(refreshToken);

    // Check if token has been reused
    const isReused = await TokenFamilyService.isTokenReused(tokenHash);

    if (isReused) {
      console.warn('⚠️ Token reuse detected:', {
        tokenHash: tokenHash.substring(0, 16) + '...',
        ip: req.ip,
        userAgent: req.get('user-agent'),
      });

      // Get token record to find family_id
      const record = await TokenFamilyService.getTokenRecord(tokenHash);

      if (record) {
        // Revoke entire token family
        await TokenFamilyService.revokeTokenFamily(record.family_id);

        console.error('🚨 Token family revoked due to reuse:', {
          familyId: record.family_id,
          userId: record.user_id,
        });
      }

      // Return 401 unauthorized
      return res.status(401).json({
        code: 'token_reused',
        message: 'Refresh token has been reused. All sessions have been revoked for security.',
        details: {
          reason: 'Token reuse indicates potential security breach',
        },
      });
    }

    // Token is valid (not reused yet)
    // Mark as consumed to detect future reuse
    await TokenFamilyService.markTokenConsumed(tokenHash);

    // Continue to auth refresh route
    next();
  } catch (error) {
    console.error('❌ Error in token reuse detection:', error);

    // Fail closed: deny request on error
    // Alternative: Fail open by calling next() to allow request
    return res.status(500).json({
      code: 'internal_error',
      message: 'Failed to validate token',
    });
  }
};
```

### Error Handling Strategy

**Error Types:**

1. **Token Reused (Security Incident)**
   - HTTP Status: 401 Unauthorized
   - Response:
     ```json
     {
       "code": "token_reused",
       "message": "Refresh token has been reused. All sessions have been revoked for security.",
       "details": { "reason": "Token reuse indicates potential security breach" }
     }
     ```
   - Action: Revoke token family, log incident

2. **Redis Connection Error**
   - HTTP Status: 500 Internal Server Error
   - Response:
     ```json
     {
       "code": "internal_error",
       "message": "Failed to validate token"
     }
     ```
   - Action: Fail closed (deny request), log error, alert operations

3. **Token Not Found in Cache**
   - HTTP Status: N/A (continue to n8n)
   - Action: Allow request (token might be new or not yet cached by n8n)
   - Rationale: Backend cache is best-effort, n8n has authoritative token store

4. **JSON Parse Error (Corrupted Cache)**
   - HTTP Status: 500 Internal Server Error
   - Action: Log error, clear corrupted key, deny request

## Validation Gates

### Manual Testing

**Test 1: Normal Token Refresh**
```bash
# 1. Login to get initial tokens
curl -X POST http://localhost:3000/api/1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"test123"}'

# Expected: 200 OK, receive access_token and refresh_token

# 2. Refresh with valid token (first time)
curl -X POST http://localhost:3000/api/1/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"<REFRESH_TOKEN>"}'

# Expected: 200 OK, receive new tokens
```

**Test 2: Token Reuse Detection**
```bash
# 1. Login to get tokens
# 2. Refresh once (token gets marked as consumed)
curl -X POST http://localhost:3000/api/1/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"<REFRESH_TOKEN>"}'

# Expected: 200 OK, new tokens

# 3. Try to reuse the SAME old token again
curl -X POST http://localhost:3000/api/1/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"<OLD_REFRESH_TOKEN>"}'

# Expected: 401 Unauthorized
# Response: { "code": "token_reused", "message": "..." }
# Backend log: "Token family revoked"
```

**Test 3: Redis Unavailable**
```bash
# 1. Stop Redis server
docker stop redis
# or
redis-cli shutdown

# 2. Try to refresh token
curl -X POST http://localhost:3000/api/1/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"<REFRESH_TOKEN>"}'

# Expected: 500 Internal Server Error
# Response: { "code": "internal_error", "message": "Failed to validate token" }
# Backend log: "Redis error: ..."
```

**Test 4: Token Not in Cache (n8n Token)**
```bash
# 1. Get token from n8n directly (not through backend)
# 2. Try to refresh it through backend
curl -X POST http://localhost:3000/api/1/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"<N8N_TOKEN>"}'

# Expected: 200 OK (token not in cache, passes to n8n)
# n8n will validate and rotate the token
```

### Verification Checklist

- [ ] Redis service connects successfully on startup
- [ ] First token refresh succeeds (200 OK)
- [ ] Second use of same token is rejected (401 Unauthorized)
- [ ] Token family is revoked on reuse detection
- [ ] Redis unavailability returns 500 error (fail closed)
- [ ] Tokens not in cache pass through to n8n
- [ ] Redis disconnects cleanly on server shutdown
- [ ] No memory leaks in Redis connection
- [ ] Error logs include relevant context (token hash, user_id, family_id)
- [ ] Security logs use WARNING level for token reuse

# Task Plan: 1.3.7 - Implementar rotação de refresh tokens

## Context and Objective

This task implements the **refresh token rotation mechanism** for the platform's authentication system. Token rotation is a critical security practice where each refresh token is used only once - when a refresh token is used to obtain new access/refresh tokens, the old refresh token is immediately invalidated and a new one is issued.

**What will be implemented:**
- Refresh token storage and lifecycle management in Redis
- Token rotation mechanism (one-time use tokens)
- Reuse detection to prevent stolen token exploitation
- Token family tracking for security breach detection
- Proper token revocation and cleanup

**Why it's needed:**
Without token rotation, a stolen refresh token can be used indefinitely until expiration (typically 7 days), creating a significant security vulnerability. Token rotation limits the window of opportunity for attackers and enables reuse detection - if a token is used twice, it indicates theft and triggers revocation of the entire token family.

**How it integrates:**
This task is part of SISTEMA 1.3 (Autenticação), specifically the Token Management component. It will be consumed by:
- Task 1.3.2: `/api/1/auth/refresh` endpoint (which triggers rotation)
- Task 1.3.3: `/api/1/auth/logout` endpoint (which revokes tokens)
- Task 1.3.4: `/api/1/auth/logout-all` endpoint (which revokes all user tokens)
- Task 1.3.9: Frontend automatic token renewal

**Business value:**
Significantly enhances platform security by preventing refresh token theft exploitation, implementing industry best practices (2025 OWASP recommendations), and providing breach detection capabilities.

**User impact:**
Transparent to users - they continue using the platform normally while being protected against token theft attacks.

### Gotchas and Pitfalls

**Token Storage:**
- ⚠️ NEVER store refresh tokens as JWTs in Redis - use opaque tokens (random UUIDs/hashes)
- ⚠️ NEVER store refresh tokens in localStorage (frontend) - use HTTP-only cookies or sessionStorage
- ⚠️ MUST set TTL (Time To Live) on Redis keys equal to refresh token expiration (auto-cleanup)
- ⚠️ Use `SETEX` instead of `SET` + `EXPIRE` to avoid race conditions

**Token Rotation:**
- ⚠️ Race condition: Multiple simultaneous refresh requests can cause token reuse false positives
  - Solution: Use Redis transactions (MULTI/EXEC) or set a small grace period (5-10 seconds)
- ⚠️ Token family tracking: Store `family_id` to enable detection of compromised token chains
- ⚠️ Clock skew: Use Unix timestamps (seconds) not milliseconds to avoid precision issues

**Redis Considerations:**
- ⚠️ Connection handling: Reuse single Redis client instance (singleton pattern)
- ⚠️ Error handling: Distinguish between token not found vs Redis connection errors
- ⚠️ Key naming: Use consistent prefix pattern (e.g., `refresh_token:{token_hash}`)
- ⚠️ Memory: Monitor Redis memory usage, implement eviction policies if needed

**Security:**
- ⚠️ Hash tokens before storing (SHA-256) - never store raw tokens in database/Redis
- ⚠️ Reuse detection: If consumed token is reused, revoke ENTIRE family (not just the token)
- ⚠️ Rate limiting: Apply rate limits to `/auth/refresh` endpoint (prevent brute force)

### Data Flow

```
[Refresh Request]
    ↓
[Extract refresh_token from request]
    ↓
[Hash token (SHA-256)] → token_hash
    ↓
[Redis: GET refresh_token:{token_hash}]
    ↓
    ├─→ [NOT FOUND] → Return 401 (Invalid Token)
    │
    ├─→ [FOUND + consumed_at EXISTS] → REUSE DETECTED!
    │       ↓
    │   [Redis: Get all tokens with same family_id]
    │       ↓
    │   [Redis: Mark ALL family tokens as revoked]
    │       ↓
    │   [Return 401 (Token Reuse Detected)]
    │
    └─→ [FOUND + NOT consumed + NOT revoked]
            ↓
        [Redis Transaction START]
            ↓
        [Mark old token as consumed (set consumed_at)]
            ↓
        [Generate new refresh_token (UUID/random)]
            ↓
        [Generate new access_token (JWT)]
            ↓
        [Store new refresh_token with same family_id]
            ↓
        [Redis Transaction COMMIT]
            ↓
        [Return new tokens]
```

  import Redis, { RedisOptions, Pipeline } from 'ioredis';
  import { config } from '../config/env.js';

  export class RedisService {
    private client: Redis | null = null;
    private connecting: Promise<void> | null = null;

    /**
     * Get Redis configuration from environment
     */
    private getRedisConfig(): RedisOptions {
      return {
        host: config.redisHost,
        port: config.redisPort,
        password: config.redisPassword,
        db: config.redisDb,
        retryStrategy(times: number) {
          const delay = Math.min(times * 50, 2000);
          return delay;
        },
        maxRetriesPerRequest: 3,
      };
    }

    /**
     * Connect to Redis (lazy initialization)
     */
    async connect(): Promise<void> {
      if (this.client) return;
      if (this.connecting) return this.connecting;

      this.connecting = (async () => {
        try {
          this.client = new Redis(this.getRedisConfig());

          this.client.on('error', (err) => {
            console.error('❌ Redis Client Error:', err);
          });

          this.client.on('connect', () => {
            console.log('✅ Redis connected');
          });

          await this.client.ping();
          this.connecting = null;
        } catch (error) {
          this.connecting = null;
          throw error;
        }
      })();

      return this.connecting;
    }

    /**
     * Get value by key
     */
    async get(key: string): Promise<string | null> {
      await this.connect();
      return this.client!.get(key);
    }

    /**
     * Set value with TTL (in seconds)
     */
    async set(key: string, value: string, ttlSeconds: number): Promise<void> {
      await this.connect();
      await this.client!.setex(key, ttlSeconds, value);
    }

    /**
     * Delete key
     */
    async delete(key: string): Promise<void> {
      await this.connect();
      await this.client!.del(key);
    }

    /**
     * Find keys by pattern
     */
    async keys(pattern: string): Promise<string[]> {
      await this.connect();
      return this.client!.keys(pattern);
    }

    /**
     * Add value to set
     */
    async sadd(key: string, ...members: string[]): Promise<void> {
      await this.connect();
      await this.client!.sadd(key, ...members);
    }

    /**
     * Get all members of set
     */
    async smembers(key: string): Promise<string[]> {
      await this.connect();
      return this.client!.smembers(key);
    }

    /**
     * Remove members from set

    async srem(key: string, ...members: string[]): Promise<void> {

#### 6. Create Token Rotation Service
- **File:** `src/backend/src/services/tokenRotation.service.ts` (NEW)
- **Details:** Implements token rotation logic per SPEC-AU-RF-*
- **Implementation:**
  ```typescript
  import crypto from 'crypto';
  import { redisService } from './redis.service.js';
  import { config } from '../config/env.js';
  import {
    RefreshTokenData,
    RotationResult,
    TokenValidationResult,
  } from '../../shared/types/auth.types.js';
  import { TokenGenerationOptions } from '../types/auth.types.js';

  export class TokenRotationService {
    private readonly KEY_PREFIX = 'refresh_token:';
    private readonly USER_TOKENS_PREFIX = 'user_tokens:';
    private readonly FAMILY_TOKENS_PREFIX = 'family_tokens:';

    /**
     * Parse JWT_REFRESH_TOKEN_EXPIRES_IN to seconds
     */
    private parseExpiresIn(expiresIn: string): number {
      const match = expiresIn.match(/^(\d+)([smhd])$/);
      if (!match) return 7 * 24 * 60 * 60; // Default 7 days

      const value = parseInt(match[1]);
      const unit = match[2];

      const multipliers = {
        s: 1,
        m: 60,
        h: 60 * 60,
        d: 24 * 60 * 60,
      };

      return value * multipliers[unit as keyof typeof multipliers];
    }

    /**
     * Hash token using SHA-256
     */
    private hashToken(token: string): string {
      return crypto.createHash('sha256').update(token).digest('hex');
    }

    /**
     * Generate random opaque token
     */
    private generateOpaqueToken(): string {
      return crypto.randomBytes(32).toString('base64url');
    }

    /**
     * Generate family ID
     */
    private generateFamilyId(): string {
      return crypto.randomBytes(16).toString('hex');
    }

    /**
     * Get TTL in seconds for refresh tokens
     */
    private getTTL(): number {
      return this.parseExpiresIn(config.jwtRefreshTokenExpiresIn);
    }

    /**
     * Store refresh token in Redis
     *
     * SPEC-AU-RF-011: Token válido DEVE gerar novo refresh token (rotação)
     */
    async storeRefreshToken(
      token: string,
      options: TokenGenerationOptions
    ): Promise<void> {
      const tokenHash = this.hashToken(token);
      const ttl = this.getTTL();
      const now = Math.floor(Date.now() / 1000);

      const tokenData: RefreshTokenData = {
        token_hash: tokenHash,
        user_id: options.userId,
        family_id: options.familyId || this.generateFamilyId(),
        issued_at: now,
        expires_at: now + ttl,
        revoked: false,
        ip_address: options.ipAddress,
        user_agent: options.userAgent,
      };

      const pipeline = redisService.multi();

      // Store token data
      pipeline.setex(
        `${this.KEY_PREFIX}${tokenHash}`,
        ttl,
        JSON.stringify(tokenData)
      );

      // Add to user's token set
      pipeline.sadd(`${this.USER_TOKENS_PREFIX}${options.userId}`, tokenHash);
      pipeline.expire(`${this.USER_TOKENS_PREFIX}${options.userId}`, ttl);

      // Add to family's token set
      pipeline.sadd(`${this.FAMILY_TOKENS_PREFIX}${tokenData.family_id}`, tokenHash);
      pipeline.expire(`${this.FAMILY_TOKENS_PREFIX}${tokenData.family_id}`, ttl);

      await pipeline.exec();
    }

    /**
     * Validate refresh token
     *
     * SPEC-AU-RF-006: Backbone DEVE validar refresh_token
     * SPEC-AU-RF-007: Backbone DEVE verificar se token não foi revogado
     * SPEC-AU-RF-008: Backbone DEVE detectar reuso de token
     */
    async validateRefreshToken(token: string): Promise<TokenValidationResult> {
      try {
        const tokenHash = this.hashToken(token);
        const key = `${this.KEY_PREFIX}${tokenHash}`;

        const dataStr = await redisService.get(key);

        // SPEC-AU-RF-018: Token inválido ou expirado DEVE retornar HTTP 401
        if (!dataStr) {
          return {
            valid: false,
            error: 'NOT_FOUND',
          };
        }

        const data: RefreshTokenData = JSON.parse(dataStr);
        const now = Math.floor(Date.now() / 1000);

        // Check expiration
        if (data.expires_at < now) {
          return {
            valid: false,
            error: 'EXPIRED',
          };
        }

        // Check revocation
        if (data.revoked) {
          return {
            valid: false,
            error: 'REVOKED',
          };
        }

        // SPEC-AU-RF-008: Detectar reuso de token
        // SPEC-AU-RF-019: Reuso detectado DEVE retornar HTTP 401
        if (data.consumed_at) {
          return {
            valid: false,
            error: 'REUSED',
            data, // Return data for family revocation
          };
        }

        return {
          valid: true,
          data,
        };
      } catch (error) {
        console.error('❌ Error validating refresh token:', error);
        return {
          valid: false,
          error: 'REDIS_ERROR',
        };
      }
    }

    /**
     * Mark token as consumed (used in rotation)
     *
     * SPEC-AU-RF-012: Refresh token antigo DEVE ser invalidado
     */
    async markTokenConsumed(tokenHash: string): Promise<void> {
      const key = `${this.KEY_PREFIX}${tokenHash}`;
      const dataStr = await redisService.get(key);

      if (!dataStr) return;

      const data: RefreshTokenData = JSON.parse(dataStr);
      data.consumed_at = Math.floor(Date.now() / 1000);

      const ttl = await redisService.client!.ttl(key);
      await redisService.set(key, JSON.stringify(data), ttl > 0 ? ttl : this.getTTL());
    }

    /**
     * Revoke entire token family (when reuse detected)
     *
     * SPEC-AU-RF-009: Reuso detectado DEVE revogar família inteira de tokens
     * SPEC-AU-RF-023: Reuso invalida toda a família
     */
    async revokeTokenFamily(familyId: string): Promise<void> {
      try {
        const familyKey = `${this.FAMILY_TOKENS_PREFIX}${familyId}`;
        const tokenHashes = await redisService.smembers(familyKey);

        if (tokenHashes.length === 0) return;

        const pipeline = redisService.multi();

        for (const tokenHash of tokenHashes) {
          const key = `${this.KEY_PREFIX}${tokenHash}`;
          const dataStr = await redisService.get(key);

          if (dataStr) {
            const data: RefreshTokenData = JSON.parse(dataStr);
            data.revoked = true;

            const ttl = await redisService.client!.ttl(key);
            pipeline.setex(key, ttl > 0 ? ttl : this.getTTL(), JSON.stringify(data));
          }
        }

        await pipeline.exec();

        console.warn(`⚠️ Token family revoked due to reuse: ${familyId}`);
      } catch (error) {
        console.error('❌ Error revoking token family:', error);
        throw error;
      }
    }

    /**
     * Revoke single token (for logout)
     *
     * SPEC-AU-LO-005: Backbone DEVE revogar o refresh_token específico
     */
    async revokeToken(token: string): Promise<void> {
      try {
        const tokenHash = this.hashToken(token);
        const key = `${this.KEY_PREFIX}${tokenHash}`;
        const dataStr = await redisService.get(key);

        if (!dataStr) return; // Token doesn't exist, idempotent

        const data: RefreshTokenData = JSON.parse(dataStr);
        data.revoked = true;

        const ttl = await redisService.client!.ttl(key);
        await redisService.set(key, JSON.stringify(data), ttl > 0 ? ttl : this.getTTL());
      } catch (error) {
        console.error('❌ Error revoking token:', error);
        throw error;
      }
    }

    /**
     * Revoke all tokens for a user (for logout-all)
     *
     * SPEC-AU-LA-008: Backbone DEVE revogar TODOS os refresh tokens do usuário
     */
    async revokeAllUserTokens(userId: string): Promise<number> {
      try {
        const userKey = `${this.USER_TOKENS_PREFIX}${userId}`;
        const tokenHashes = await redisService.smembers(userKey);

        if (tokenHashes.length === 0) return 0;

        const pipeline = redisService.multi();

        for (const tokenHash of tokenHashes) {
          const key = `${this.KEY_PREFIX}${tokenHash}`;
          const dataStr = await redisService.get(key);

          if (dataStr) {
            const data: RefreshTokenData = JSON.parse(dataStr);
            data.revoked = true;

            const ttl = await redisService.client!.ttl(key);
            pipeline.setex(key, ttl > 0 ? ttl : this.getTTL(), JSON.stringify(data));
          }
        }

        await pipeline.exec();

        return tokenHashes.length;
      } catch (error) {
        console.error('❌ Error revoking all user tokens:', error);
        throw error;
      }
    }

    /**
     * Generate new refresh token (opaque)
     */
    generateRefreshToken(): string {
      return this.generateOpaqueToken();
    }
  }

  // Export singleton instance
  export const tokenRotationService = new TokenRotationService();
  ```

### Error Handling Strategy

**Error Types:**

1. **Redis Connection Errors:**
   - **Handling:** Retry with exponential backoff (configured in RedisService)
   - **User Experience:** Return HTTP 503 Service Unavailable
   - **Logging:** Log full error with context

2. **Token Not Found:**
   - **Handling:** Return validation result with `error: 'NOT_FOUND'`
   - **User Experience:** HTTP 401 Unauthorized
   - **Response:** `{ code: 401, message: 'Invalid or expired refresh token' }`

3. **Token Reuse Detected:**
   - **Handling:** Revoke entire token family, return validation result with `error: 'REUSED'`
   - **User Experience:** HTTP 401 Unauthorized
   - **Response:** `{ code: 401, message: 'Token reuse detected. All sessions revoked.' }`
   - **Security:** Log incident with user_id, family_id, IP address

4. **Token Expired:**
   - **Handling:** Return validation result with `error: 'EXPIRED'`
   - **User Experience:** HTTP 401 Unauthorized
   - **Response:** `{ code: 401, message: 'Refresh token expired' }`

5. **Token Revoked:**
   - **Handling:** Return validation result with `error: 'REVOKED'`
   - **User Experience:** HTTP 401 Unauthorized
   - **Response:** `{ code: 401, message: 'Token has been revoked' }`

**Error Display Pattern:**
```typescript
// Pattern from: src/backend/src/middleware/errorHandler.middleware.ts
const error: any = new Error('Token reuse detected');
error.statusCode = 401;
error.details = {
  family_id: tokenData.family_id,
  user_id: tokenData.user_id,
};
next(error);
```

**Logging Pattern:**
```typescript

  timestamp: new Date().toISOString(),
  user_id: tokenData.user_id,
  family_id: tokenData.family_id,
  ip_address: req.ip,
  user_agent: req.get('user-agent'),
});
```

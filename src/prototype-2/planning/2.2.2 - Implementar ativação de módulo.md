# Task Plan: 2.2.2 - Implementar ativação de módulo

## Context and Objective

This task implements module activation functionality, allowing administrators to activate a module in a specific portal. Module activation is a critical operation that makes a module's functionality available within a portal, enabling its routes, components, and features.

**Business Value:** Enables dynamic composition of portal functionality by allowing selective activation of modules without code deployment. Supports the "build once, reuse infinitely" philosophy of the platform.

**User Impact:** Administrators can tailor each portal's functionality by activating only the modules needed, creating specialized experiences for different user groups or business units.

**Integration:** Integrates with the module listing UI (Task 2.2.1), JQEL mutation system, and portal configuration management. Must respect dependency resolution (Task 2.2.4 will enhance this with automatic dependency activation).

```typescript
import { updateRecord } from '../../services/jqel/mutations';
import { queryKeys } from '../../services/jqel/queryKeys';

export function useUpdateModule() {
  const queryClient = useQueryClient();

  return useOptimisticMutation<Module, { moduleId: string; values: Partial<Module> }>({

      return updateRecord<Module>(
        'backend',
        'module',
        { moduleId: { $eq: moduleId } },

      queryClient.invalidateQueries({
        queryKey: queryKeys.backend.module(moduleId),
      });
      queryClient.invalidateQueries({
        queryKey: queryKeys.backend.modules(),
      });
    },
  });
}
```

### Gotchas and Pitfalls
- ⚠️ **Dual update required:** Activating a module requires updating BOTH portal.activeModules array AND module.portals array. This is a consistency requirement.
- ⚠️ **Optimistic update complexity:** Need to optimistically update both Portal and Module caches, and rollback both on error.
- ⚠️ **Module already active:** Check if module is already active in portal before allowing activation (prevent duplicate activation).
- ⚠️ **Dependencies:** For now, assume dependencies are manually handled. Task 2.2.4 will add automatic dependency resolution.
- ⚠️ **Portal selection:** User must select target portal for activation (modules can be active in multiple portals).

## Implementation Blueprint

### Ordered Steps

1. **Create Module Activation Hook**
   - Create: `src/prototype-2/frontend/src/modules/setup/hooks/useModuleActivation.ts`
   - Details: Custom hook orchestrating activation logic with optimistic updates
   - Pattern: TanStack Query mutations with optimistic rollback
   ```typescript
   import { useQueryClient } from '@tanstack/react-query';
   import { useUpdateModule } from '../../../hooks/jqel/useModuleMutations';
   import { useUpdatePortal } from '../../../hooks/jqel/usePortalMutations';
   import { queryKeys } from '../../../services/jqel/queryKeys';
   import { toast } from '../../../hooks/use-toast';
   import type { Module } from '../../../types/module';
   import type { Portal } from '../../../types/portal';

   export function useModuleActivation() {
     const queryClient = useQueryClient();
     const updateModule = useUpdateModule();
     const updatePortal = useUpdatePortal();

     const activateModule = async (moduleId: string, portalId: string) => {
       try {
         // 1. Get current portal data
         const portal = queryClient.getQueryData<Portal>(
           queryKeys.backend.portal(portalId)
         );
         if (!portal) {
           throw new Error('Portal not found');
         }

         // 2. Check if already active
         if (portal.activeModules.includes(moduleId)) {
           toast({
             title: 'Already active',
             description: 'This module is already active in the selected portal',
             variant: 'warning',
           });
           return;
         }

         // 3. Get current module data
         const module = queryClient.getQueryData<Module>(
           queryKeys.backend.module(moduleId)
         );
         if (!module) {
           throw new Error('Module not found');
         }

         // 4. Optimistic update: Portal
         const newActiveModules = [...portal.activeModules, moduleId];
         queryClient.setQueryData<Portal>(
           queryKeys.backend.portal(portalId),
           { ...portal, activeModules: newActiveModules }
         );

         // 5. Optimistic update: Module
         const newPortals = module.portals ? [...module.portals, portalId] : [portalId];
         queryClient.setQueryData<Module>(
           queryKeys.backend.module(moduleId),
           { ...module, portals: newPortals, active: true }
         );

         // 6. Execute mutations
         await updatePortal.mutateAsync({
           portalId,
           values: { activeModules: newActiveModules },
         });

         await updateModule.mutateAsync({
           moduleId,
           values: {
             portals: newPortals,
             active: true,
           },
         });

         // 7. Success feedback
         toast({
           title: 'Module activated',
           description: `${module.name} is now active in ${portal.name}`,
           variant: 'success',
           duration: 3000,
         });

         // 8. Invalidate queries
         queryClient.invalidateQueries({ queryKey: queryKeys.backend.portals() });
         queryClient.invalidateQueries({ queryKey: queryKeys.backend.modules() });

       } catch (error) {
         // Rollback optimistic updates
         queryClient.invalidateQueries({ queryKey: queryKeys.backend.portal(portalId) });
         queryClient.invalidateQueries({ queryKey: queryKeys.backend.module(moduleId) });

         // Error feedback
         toast({
           title: 'Activation failed',
           description: error instanceof Error ? error.message : 'Unknown error',
           variant: 'error',
           duration: 5000,
         });

         throw error;
       }
     };

     return {
       activateModule,
       isActivating: updateModule.isPending || updatePortal.isPending,
       error: updateModule.error || updatePortal.error,
     };
   }
   ```

   ```typescript
     module,
     isOpen,
     onClose,
     onConfirm,
   ```

   ```typescript
             <div className="mt-3 text-sm text-muted-foreground">
               Dependencies: {module.dependencies.join(', ')}
             </div>
           )}

           {/* Activation Button */}
           <div className="mt-4">
             <button
               onClick={() => setIsDialogOpen(true)}
               disabled={isActivating}
               className="w-full px-4 py-2 text-sm font-medium text-primary border border-primary rounded-md hover:bg-primary hover:text-primary-foreground focus:ring-2 focus:ring-primary focus:ring-offset-2 disabled:opacity-50 disabled:cursor-not-allowed transition-colors"
             >
               {isActivating ? 'Activating...' : 'Activate in Portal...'}
             </button>
           </div>
         </div>

         {/* Activation Dialog */}
         <ModuleActivationDialog
           module={module}
           isOpen={isDialogOpen}
           onClose={() => setIsDialogOpen(false)}
           onConfirm={handleActivate}
           isActivating={isActivating}
         />
       </>
     );
   }
   ```

### Error Handling Strategy

**Error Types:**
- Portal not found: Display error toast, log to console
- Module not found: Display error toast, log to console
- Module already active: Display warning toast, no action taken
- Network error: Display error toast with retry suggestion
- Validation error: Display inline error in dialog
- Mutation failure: Rollback optimistic updates, display error toast

**Error Display Pattern:**
```typescript
try {
  await activateModule(moduleId, portalId);
} catch (error) {
  toast({
    title: 'Activation failed',
    description: error instanceof Error ? error.message : 'Unknown error occurred',
    variant: 'error',
    duration: 5000
  });

  // Log detailed error for debugging
  if (import.meta.env.DEV) {
    console.error('Module activation error:', error);
  }
}
```

**Rollback Strategy:**
```typescript
// On error, invalidate queries to refetch fresh data
queryClient.invalidateQueries({ queryKey: queryKeys.backend.portal(portalId) });
queryClient.invalidateQueries({ queryKey: queryKeys.backend.module(moduleId) });
```
